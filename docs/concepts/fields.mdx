title: Fields
---

Fields define the individual inputs shown within a section. Use them to capture responses, validate them, and control when a question should appear.

## Overview

Every field shares a common base shape, including an identifier, a field type, and the content shown to the respondent. Field types extend this base structure with their own properties, while validators and visibility rules control how a field behaves at runtime.

## Structure

```yaml
id: question_1
type: email
label: What’s your email?
placeholder: hello@declarativeforms.com
validators:
  - required
visible_when: data.contact_method === 'email'
```

</ParamField>

</ParamField>
