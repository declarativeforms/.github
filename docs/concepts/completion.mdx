---
title: Completion
---

Completion defines the thank-you experience shown after a form is submitted successfully. Use it when you want to control the final message and optional next step shown to the respondent.

## Overview

The completion object controls the content rendered on the form's completion screen. It can define a title, a message, and an optional button, all at the form level.

## Structure

```yaml
title: "Thank you!"
message: "We have received your submission."
button:
  label: "Continue"
  url: "https://example.com"
```

## Fields

<ParamField path="title" type="string | object">
  Defines the title shown after the form is completed.
</ParamField>

<ParamField path="message" type="string | object">
  Defines the message shown below the completion title.
</ParamField>

<ParamField path="button" type="object">
  Defines the optional button shown on the completion screen.
</ParamField>

<ParamField path="button.label" type="string | object">
  Defines the label shown on the completion button.
</ParamField>

<ParamField path="button.url" type="string | object">
  Defines the URL opened when the completion button is clicked.
</ParamField>

## Details

When `completion` is not provided, the platform shows the default thank-you title and description.

The completion button is only shown when a button URL is provided.

The completion title, message, and button URL support template interpolation using submission data.
