title: Sections
---

Sections split a form into steps. Use them to group related fields and control how respondents move through the form.

## Overview

Each section defines the content rendered for one step in the flow. A section contains its own fields and points to what should happen next. In the simplest case, `next: done` completes the form, while more advanced flow control is covered in [conditional navigation](/concepts/conditional_navigation).

## Structure

```yaml
id: section_1
title: "Section 1"
fields:
  - id: question_1
    type: email
    label: What’s your email?
    placeholder: hello@declarativeforms.com
    validators:
      - required
next: done
```

## Fields

<ParamField path="id" type="string" required>
  Defines the unique identifier used to reference the section.
</ParamField>

<ParamField path="title" type="string | object" required>
  Defines the title shown for the section.
</ParamField>

<ParamField path="fields" type="array" required>
  Defines the fields rendered within the section. See [fields](/concepts/fields) for more details.
</ParamField>

<ParamField path="next" type="string | array" required>
  Defines where the form should go after the section is submitted. See [conditional navigation](/concepts/conditional_navigation) for more details.
</ParamField>
