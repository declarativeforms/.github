---
title: Sections
---

## Structure

```yaml
# ...

sections:
  - id: section_1
    title: "Section 1"
    fields:
      - id: question_1
        type: email
        label: What’s your email?
        placeholder: hello@declarativeforms.com
        validators:
          - required
    next: done

# ...
```

## Fields

<ParamField path="id" type="string" required>
  Defines the unique identifier used to reference the section.
</ParamField>

<ParamField path="title" type="string | object" required>
  Defines the title shown for the section.
</ParamField>

<ParamField path="fields" type="array" required>
  Defines the fields rendered within the section.
</ParamField>

<ParamField path="next" type="string" required>
  Defines where the form should go after the section is submitted.
</ParamField>
