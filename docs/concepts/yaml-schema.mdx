A Declarative Forms configuration file is a YAML file committed to a GitHub repository. This page builds up the full schema one piece at a time, starting from the smallest valid file.

---

## The minimum valid YAML

Every form needs three keys: `version`, `title`, and `sections`. Here is the canonical form from the quickstart, stripped to a single field:

```yaml
version: 1
title: Feedback
sections:
  - id: main
    title: Share your feedback
    fields:
      - id: name
        type: short_text
        label: Your name
    next: done
```

That's a working form. Everything else is optional.

---

## Adding `description`

`description` renders as a subtitle below the form title:

```yaml
version: 1
title: Feedback
description: Takes about 30 seconds.
sections:
  - id: main
    title: Share your feedback
    fields:
      - id: name
        type: short_text
        label: Your name
      - id: message
        type: short_text
        label: Your message
    next: done
```

## Optional top-level keys

Each of these keys adds a capability to the form. They are introduced briefly here; each has a dedicated concept page.

### `connections`

Triggers actions after the form is completed — send data to a webhook, send an email, or write a row to Airtable.

```yaml
connections:
  - type: webhook
    url: https://your-api.com/hooks/feedback
```

See [Connections](/concepts/connections).

### `completion`

Customizes the thank-you page shown after the final section is submitted. Supports `{{data.fieldId}}` interpolation.

```yaml
completion:
  title: "Thanks, {{data.name}}!"
  message: We received your message.
```

### `start_date` / `end_date`

Makes the form inaccessible outside a date window. Both accept ISO 8601 strings.

```yaml
start_date: "2025-09-01"
end_date: "2025-09-30"
```

### `locale`

Locks the form to a specific language. Without this key, the locale is resolved from the browser.

```yaml
locale: es
```

See [Localization](/concepts/localization).

### `mixpanel`

Enables analytics events (`page_view` and `section_completed`) sent to your Mixpanel project.

```yaml
mixpanel: "your-project-token"
```

## Full example

The canonical form with all optional top-level keys included:

```yaml
version: 1
title: Feedback
description: Takes about 30 seconds.
start_date: "2025-01-01"
end_date: "2025-12-31"
locale: en
mixpanel: "your-project-token"

sections:
  - id: main
    title: Share your feedback
    fields:
      - id: name
        type: short_text
        label: Your name
      - id: message
        type: short_text
        label: Your message
    next: done

connections:
  - type: webhook
    url: https://your-api.com/hooks/feedback

completion:
  title: "Thanks, {{data.name}}!"
  message: We received your message.
```
