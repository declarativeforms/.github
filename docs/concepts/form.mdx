title: Form
description: What is a Form?
---

Declarative Forms is a developer-first alternative to traditional form platforms. Instead of building forms through visual editors, you define forms as YAML configuration in a GitHub repository.

---

## Structure

```yaml
version: 1
title: "Quick Feedback"
description: "Help us make Declarative Forms better!"
sections:
  - id: main
    title: "Your Feedback"
    fields:
      - id: feedback
        type: long_text
        label: "What can we improve?"
        validators:
          - required
    next: done
connections:
  - type: webhook
    url: https://your-api.com/hooks/form
```
