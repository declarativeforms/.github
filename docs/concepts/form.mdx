---
title: Form
description: The top-level structure that defines a form's identity.
---

A form is a YAML file that contains everything the platform needs to render and process a set of inputs. At minimum, it requires a schema version, a title, and one or more sections.

```yaml
version: 1
title: Registration Form
description: Sign up for early access.

sections:
  - id: signup
    title: Your Details
    fields:
      - id: email
        type: email
        label: Email
        validators:
          - required
    next: done
```

- **`version`** — Always `1`. Identifies the schema version.
- **`title`** — The name displayed at the top of the form.
- **`description`** — An optional subtitle shown below the title.
- **`sections`** — The form's content, defined as an ordered array. See [Sections](/concepts/sections).
- **`connections`** — An optional array of integrations triggered on submission. See [Connections](/concepts/connections).
