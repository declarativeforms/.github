---
title: Scheduling
description: How to restrict a form to a specific time window.
---

You can control when a form accepts submissions using `start_date` and `end_date`. Outside of this window, visitors see a message instead of the form.

```yaml
version: 1
title: Contest Entry
start_date: "2026-03-01"
end_date: "2026-03-31"

sections:
  - id: entry
    title: Enter the Contest
    fields:
      - id: name
        type: short_text
        label: Name
        validators:
          - required
    next: done
```

- **`start_date`** — The earliest date the form accepts submissions. Visitors who arrive before this date see a "form not yet open" message.
- **`end_date`** — The latest date the form accepts submissions. Visitors who arrive after this date see a "form closed" message.

Both values are ISO 8601 date strings. You can use either property independently — for example, a form with only a `start_date` opens on that date and stays open indefinitely.
