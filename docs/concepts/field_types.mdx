title: Field Types
---

Field types define the specific input experience a field renders. Use them to choose the simplest input that fits the kind of data you want to collect.

## Overview

Each field type shares the base field properties documented in the [fields](/concepts/fields) page, then adds any type-specific settings such as options, rating labels, or address output formats. Start with the simplest field that fits the use case, then move to more specialized field types only when the interaction requires it.

## `short_text`

Use a short text field for simple single-line answers such as names, short identifiers, or brief responses.

```yaml
id: question_1
type: short_text
label: What's your name?
```
