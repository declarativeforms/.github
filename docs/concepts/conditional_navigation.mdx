---
title: Conditional Navigation
---

Conditional navigation controls where a form goes after a section is submitted. Use it when the next step should depend on the respondent's answers instead of following a fixed path.

## Overview

Section navigation starts from the `next` property. In the simplest case, `next` points to another section id or to `done`, but it can also use an ordered list of conditional rules to branch to different destinations.

Conditional navigation uses the same expression model described in [expressions](/concepts/expressions). It applies that logic at the section level to control how the overall flow moves forward.

## Structure

A section can move directly to another section or to `done`:

```yaml
next: contact_details
```

Conditional rules can branch to different destinations:

```yaml
next:
  - when: data.account_type === "business"
    go: company_details
  - when: data.account_type === "personal"
    go: personal_details
  - else: done
```

An external `https://` URL can be used to redirect after submission:

```yaml
next: "https://example.com/thank-you"
```

## Fields

<ParamField path="next" type="string | array" required>
  Defines where the form should go after the section is submitted.
</ParamField>

<ParamField path="when" type="string">
  Defines the expression that must match before the navigation rule is used.
</ParamField>

<ParamField path="go" type="string">
  Defines the section or destination used when the condition matches.
</ParamField>

<ParamField path="else" type="string">
  Defines the fallback section or destination used when no prior condition matches.
</ParamField>

## Details

Conditional rules are evaluated in order, and the first matching `when` rule is used.

If an `else` rule is provided, it is used as the fallback when no earlier condition matches. If no rule matches and no `else` rule is provided, navigation falls back to `done`.

When the resolved destination starts with `https://`, the form submits and then redirects to that URL instead of continuing to another section.
