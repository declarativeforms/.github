---
title: Analytics
description: How to track form views and section completions with Mixpanel.
---

You can track user interactions using Mixpanel. Add a `mixpanel` property to your form with your project token, and the platform automatically records events — no custom code required.

```yaml
version: 1
title: Feedback Form
mixpanel: abc123def456

sections:
  - id: feedback
    title: Your Feedback
    fields:
      - id: message
        type: long_text
        label: Message
        validators:
          - required
    next: done
```

- **`mixpanel`** — Your Mixpanel project token. When present, the platform tracks events automatically.

---

## Tracked events

The platform records two events.

| Event | Fires when | Properties |
|---|---|---|
| `page_view` | The form loads | `form_id` |
| `section_completed` | A section is submitted | `form_id`, `section_id` |

- **`page_view`** — Tells you how many people open the form.
- **`section_completed`** — Shows how far users progress and where they drop off.

Use these events in Mixpanel funnels to measure completion rates across sections.

---

## Data routing

The platform sends all events to Mixpanel's EU endpoint (`api-eu.mixpanel.com`). No additional configuration is needed to control the data region.
