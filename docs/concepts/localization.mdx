---
title: Localization
description: How to translate form labels and text into multiple languages.
---

By default, YAML text values are plain strings and render the same for every user. To support multiple languages, replace any string value with a **locale map** — an object where keys are locale codes and values are translations.

Supported locales: `en` (English) and `es` (Spanish).

---

## Converting `title` to a locale map

Start with the canonical form's plain string title:

```yaml
version: 1
title: Feedback
```

Replace it with a locale map:

```yaml
version: 1
title:
  en: Feedback
  es: Comentarios
```

The platform picks the correct value based on the active locale.

---

## Converting field labels

Do the same for field `label` values:

```yaml
sections:
  - id: main
    title:
      en: Share your feedback
      es: Comparte tus comentarios
    fields:
      - id: name
        type: short_text
        label:
          en: Your name
          es: Tu nombre
      - id: message
        type: short_text
        label:
          en: Your message
          es: Tu mensaje
    next: done
```

Any field that accepts a string also accepts a locale map: `title`, `description`, `label`, `placeholder`, validator `message`, and `completion` text.

---

## The `locale` top-level key

To lock the form to a specific language regardless of the user's browser, set `locale` at the top level:

```yaml
version: 1
locale: es
title:
  en: Feedback
  es: Comentarios
sections:
  - id: main
    title:
      en: Share your feedback
      es: Comparte tus comentarios
    fields:
      - id: name
        type: short_text
        label:
          en: Your name
          es: Tu nombre
      - id: message
        type: short_text
        label:
          en: Your message
          es: Tu mensaje
    next: done
```

When `locale` is set, the platform adds `?lang=es` to the URL automatically to keep the locale consistent across sections.

---

## `?lang=` URL override

Append `?lang=es` to any form URL to override the locale:

```
https://app.declarativeforms.com/acme/forms/feedback?lang=es
```

This is useful for multilingual marketing campaigns or embedding forms in language-specific pages.

---

## Resolution priority

The active locale is determined in this order:

1. `?lang=` query parameter
2. Browser's `navigator.language`
3. `locale` key in the YAML
4. `en` as the final fallback

The `?lang=` parameter always takes precedence — including over the YAML `locale` key.
