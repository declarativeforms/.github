---
title: Conditional Visibility
---

Conditional visibility lets a field appear only when it becomes relevant. Use it when later questions should depend on answers given earlier in the form.

## Overview

Conditional visibility is controlled per field through `visible_when`. The expression is evaluated against the current form data, and the field is shown only when the expression matches.

This keeps a form focused by hiding questions until they are needed. See [expressions](/concepts/expressions) for more details on how expressions are written.

## Structure

```yaml
fields:
  - id: account_type
    type: single_select
    label: "Which type of account are you creating?"
    options:
      - personal
      - business

  - id: company_name
    type: short_text
    label: "What's your company name?"
    visible_when: data.account_type === "business"
```

## Fields

<ParamField path="visible_when" type="string">
  Defines the expression used to determine whether the field is shown.
</ParamField>

## Details

When `visible_when` is not provided, the field is shown by default.

The visibility expression is re-evaluated as form data changes.
