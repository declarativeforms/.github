This example demonstrates a complete beta signup form with:
- OTP email verification
- Hidden UTM tracking fields populated via URL parameters
- Confirmation email to the user
- Airtable integration for the waitlist
- Webhook for CRM integration

## YAML

```yaml
version: 1
title: Join the Beta
description: Get early access and help shape the product.

sections:
  - id: signup
    title: Your information
    fields:
      - id: name
        type: short_text
        label: Full name
        validators:
          - required

      - id: email
        type: email
        label: Email address
        otp: true
        validators:
          - required

      - id: company
        type: short_text
        label: Company or organization

      - id: role
        type: single_select
        label: Your role
        options:
          - Software Engineer
          - Engineering Manager
          - Product Manager
          - Designer
          - DevOps / Platform
          - Founder / CTO
          - Other
        validators:
          - required

    next: use_case

  - id: use_case
    title: How you'll use it
    fields:
      - id: primary_use_case
        type: long_text
        label: What are you looking to build or solve?
        validators:
          - required
          - type: min
            value: 30
            message: Please tell us a bit more (at least 30 characters).

      - id: team_size
        type: single_select
        label: Team size
        options:
          - Just me
          - 2–10
          - 11–50
          - 51–200
          - 200+

      - id: current_tool
        type: short_text
        label: What form tool do you use today? (if any)
        placeholder: Typeform, Google Forms, custom-built, none...

      # Hidden UTM tracking fields
      - id: utm_source
        type: hidden
        label: UTM Source

      - id: utm_medium
        type: hidden
        label: UTM Medium

      - id: utm_campaign
        type: hidden
        label: UTM Campaign

      - id: referral_code
        type: hidden
        label: Referral Code

    next: done

connections:
  - type: email
    to: "{{data.email}}"
    subject: "You're on the list, {{data.name}}!"
    body: |
      <p>Hi {{data.name}},</p>
      <p>Thanks for signing up for early access. We're onboarding people in waves and will reach out to you directly at this address when your spot is ready.</p>
      <p>In the meantime, you can follow along on <a href="https://github.com/declarativeforms/examples">GitHub</a>.</p>
      <p>— The Team</p>

  - type: airtable
    connection_id: your-airtable-connection-id
    base_id: appXXXXXXXXXXXXXX
    table_id_or_name: Beta Waitlist

  - type: webhook
    url: https://your-crm.example.com/hooks/beta-signup

completion:
  title: "You're on the list, {{data.name}}!"
  message: We'll reach out when your early access spot is ready. Keep an eye on your inbox.
  button:
    label: Follow our progress on GitHub
    url: https://github.com/declarativeforms/examples
```

## How UTM tracking works

Include UTM parameters in your marketing links:

```
https://app.declarativeforms.com/acme/forms/beta?utm_source=twitter&utm_medium=social&utm_campaign=launch2025
```

The hidden fields `utm_source`, `utm_medium`, and `utm_campaign` are populated automatically. They appear in your Airtable records and webhook payload alongside the signup data.

See [Pass hidden tracking data](/guides/pass-hidden-tracking-data) for details.

## Airtable column setup

Create a table with these columns:

| Column name | Airtable type |
|-------------|---------------|
| `name` | Single line text |
| `email` | Email |
| `company` | Single line text |
| `role` | Single select |
| `primary_use_case` | Long text |
| `team_size` | Single select |
| `current_tool` | Single line text |
| `utm_source` | Single line text |
| `utm_medium` | Single line text |
| `utm_campaign` | Single line text |
| `referral_code` | Single line text |

## How to use this

1. Replace Airtable `connection_id`, `base_id`, and `table_id_or_name` with your values
2. Replace the webhook URL with your CRM endpoint
3. Update UTM field IDs to match your tracking parameters
4. Customize the confirmation email body
