---
title: Collect Phone Numbers
description: Add a phone number field with international format support.
---

The `phone` field in the personal section collects the applicant's phone number in international format.

---

## What to add

Add a `mobile_number` field to the `personal` section of `rental.yaml`:

```yaml
      - id: phone
        type: mobile_number
        label: Phone number
        validators:
          - required
```

---

## How it works

`mobile_number` renders a phone input with a country code selector. The applicant selects their country and enters their number — the field validates that it is a plausible mobile number for that country.

**Submission value type:** `string` in E.164 format (e.g., `+12025551234`). The country code is included in the stored value regardless of how the applicant entered it.

### Validators

| Validator | Description |
|-----------|-------------|
| `required` | A valid number must be entered. |
