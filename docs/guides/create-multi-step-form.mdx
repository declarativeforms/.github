---
title: Create a multi-step form
description: How to split a form into multiple sections with navigation
---

Multi-step forms break a long form into discrete sections. Each section is submitted individually, and progress is saved automatically between steps.

## How it works

Each section has a `next` property pointing to the next section's `id`. The form starts with the **first section** defined in the `sections` array.

Use the special value `"done"` as the `next` for the final section.

## Example: 3-section onboarding form

```yaml
version: 1
title: Account Setup

sections:
  - id: personal_info
    title: About you
    fields:
      - id: first_name
        type: short_text
        label: First name
        validators:
          - required
      - id: last_name
        type: short_text
        label: Last name
        validators:
          - required
      - id: email
        type: email
        label: Work email
        validators:
          - required
    next: company_info

  - id: company_info
    title: Your company
    fields:
      - id: company_name
        type: short_text
        label: Company name
        validators:
          - required
      - id: company_size
        type: single_select
        label: Company size
        options:
          - "1–10"
          - "11–50"
          - "51–200"
          - "200+"
        validators:
          - required
      - id: industry
        type: dropdown
        label: Industry
        searchable: true
        options:
          - Technology
          - Finance
          - Healthcare
          - Education
          - Other
    next: use_case

  - id: use_case
    title: How you'll use it
    fields:
      - id: primary_use
        type: long_text
        label: What will you primarily use this for?
        validators:
          - required
      - id: referral
        type: short_text
        label: How did you hear about us?
    next: done

connections:
  - type: email
    to: onboarding@example.com
    subject: "New signup: {{data.first_name}} {{data.last_name}}"
    include_responses: true
```

## Section IDs

Section IDs must be:
- Unique within the form
- Free of spaces (use `_` or `-`)
- Referenced exactly in `next` values

If a `next` value references a section ID that doesn't exist, the form will fail to navigate.

## Progress saving

After each section is submitted, the platform saves a partial submission and updates the browser URL:

```
?submission_id=abc123&step=company_info
```

Users can resume from this URL at any time. See [Resume a form submission](/guides/resume-form-submission) for details.

## Conditional navigation

To branch between sections based on user input, use the conditional `next` syntax. See [Conditional navigation](/guides/conditional-navigation).

## Connections and multi-step forms

Connections only fire after the **final section** is submitted, not after intermediate sections. This means all data across all sections is available when connections execute.
