---
title: Multilingual option labels
description: How to translate dropdown and select option labels
---

For selection fields (`dropdown`, `single_select`, `multiple_select`, `rating`), options can have translated labels using the structured option format.

## Structured option syntax

Instead of a plain string, use an object with `value` and `label`:

```yaml
options:
  - value: us
    label:
      en: United States
      es: Estados Unidos
  - value: mx
    label:
      en: Mexico
      es: México
```

The `value` is what gets stored in the submission. The `label` is what the user sees—it changes based on the active locale.

## Simple vs structured options

You can mix simple strings and structured objects in the same `options` array if only some options need translation:

```yaml
options:
  - Other           # simple string — shown as-is in all locales
  - value: us
    label:
      en: United States
      es: Estados Unidos
```

## Full example

```yaml
version: 1
title:
  en: Customer Survey
  es: Encuesta de clientes

sections:
  - id: main
    title:
      en: Your preferences
      es: Tus preferencias
    fields:
      - id: country
        type: dropdown
        label:
          en: Country
          es: País
        searchable: true
        options:
          - value: us
            label:
              en: United States
              es: Estados Unidos
          - value: es
            label:
              en: Spain
              es: España
          - value: mx
            label:
              en: Mexico
              es: México
          - value: ar
            label:
              en: Argentina
              es: Argentina

      - id: satisfaction
        type: single_select
        label:
          en: How satisfied are you?
          es: ¿Qué tan satisfecho estás?
        options:
          - value: very_satisfied
            label:
              en: Very satisfied
              es: Muy satisfecho
          - value: satisfied
            label:
              en: Satisfied
              es: Satisfecho
          - value: neutral
            label:
              en: Neutral
              es: Neutral
          - value: dissatisfied
            label:
              en: Dissatisfied
              es: Insatisfecho
    next: done
```

## Submission data

Regardless of the locale, the **`value`** is stored in the submission—not the translated label. This means your submission data is locale-independent:

```json
{
  "country": "us",
  "satisfaction": "very_satisfied"
}
```

This makes it safe to compare or aggregate submission data across different language submissions.

## Rating fields

Rating fields also support locale maps for `min_label` and `max_label` (the labels shown at the ends of the rating scale):

```yaml
- id: nps
  type: rating
  label:
    en: How likely are you to recommend us?
    es: ¿Qué tan probable es que nos recomiendas?
  min_label:
    en: Not at all likely
    es: Para nada probable
  max_label:
    en: Extremely likely
    es: Extremadamente probable
```
