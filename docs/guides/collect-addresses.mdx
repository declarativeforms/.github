---
title: Collect addresses
description: How to collect structured address data with Google Places autocomplete
---

Declarative Forms provides four address field types powered by Google Places autocomplete. They differ in the scope of the address component they collect.

## Address field types

| Type | Collects |
|------|---------|
| `address` | Full address (street, city, state, country, postal code) |
| `address_locality` | City / locality |
| `address_region` | State / region / administrative area |
| `address_country` | Country |

## Basic usage

```yaml
- id: shipping_address
  type: address
  label: Shipping address
```

## Output format

By default, the field stores the formatted address as a string:

```json
{
  "shipping_address": "1600 Amphitheatre Parkway, Mountain View, CA 94043, USA"
}
```

To get structured data, set `outputFormat: "structured"`:

```yaml
- id: shipping_address
  type: address
  label: Shipping address
  outputFormat: structured
```

With `outputFormat: "structured"`, the field value is a JSON object:

```json
{
  "shipping_address": {
    "formatted_address": "1600 Amphitheatre Parkway, Mountain View, CA 94043, USA",
    "street_number": "1600",
    "route": "Amphitheatre Parkway",
    "locality": "Mountain View",
    "administrative_area_level_1": "CA",
    "country": "US",
    "postal_code": "94043",
    "place_id": "ChIJ2eUgeAK6j4ARbn5u_wAGqWA"
  }
}
```

## Structured output fields

| Field | Description |
|-------|-------------|
| `formatted_address` | Full formatted address string |
| `street_number` | House/building number |
| `route` | Street name |
| `locality` | City |
| `administrative_area_level_1` | State or region (short code where available) |
| `country` | Country code |
| `postal_code` | ZIP or postal code |
| `place_id` | Google Places ID |

Some fields may be absent if the selected place doesn't include that component.

## Collecting multiple address components

Use multiple address field types together:

```yaml
- id: city
  type: address_locality
  label: City

- id: state
  type: address_region
  label: State

- id: country
  type: address_country
  label: Country
```

## Full example

```yaml
version: 1
title: Delivery Details

sections:
  - id: delivery
    title: Where should we deliver?
    fields:
      - id: name
        type: short_text
        label: Recipient name
        validators:
          - required

      - id: address
        type: address
        label: Delivery address
        outputFormat: structured
        validators:
          - required
    next: done
```

## Notes

- Address fields use the Google Places API for autocomplete suggestions
- Users must select a suggestion from the dropdown—freeform text entry is not stored unless a suggestion is selected
- The `address_locality`, `address_region`, and `address_country` types show suggestions scoped to that component type
