---
title: Capture signatures
description: How to collect a digital signature in a form
---

The `signature` field type provides an HTML5 canvas for users to draw a signature. The drawing is uploaded as a PNG and the submission data contains the URL.

## Configuration

```yaml
- id: signature
  type: signature
  label: Sign here
  validators:
    - required
```

## User experience

- Users draw their signature using mouse, touch, or a stylus
- The canvas is 160px tall
- A **Clear** button allows the user to redraw
- The signature is uploaded automatically as a debounced background operation as the user draws

## Submission value

The field value in `submission.data` is a string URL pointing to the PNG file:

```json
{
  "signature": "https://storage.example.com/signatures/sig-abc123.png"
}
```

## Making the signature required

Add `required` to ensure the user has drawn a signature before submitting:

```yaml
- id: signature
  type: signature
  label: Signature
  validators:
    - required
```

## Full example

```yaml
version: 1
title: Service Agreement

sections:
  - id: agreement
    title: Review and sign
    fields:
      - id: full_name
        type: short_text
        label: Full legal name
        validators:
          - required

      - id: date_signed
        type: date
        label: Date
        validators:
          - required

      - id: signature
        type: signature
        label: Signature
        validators:
          - required
    next: done

connections:
  - type: email
    to: legal@example.com
    subject: "Agreement signed by {{data.full_name}}"
    include_responses: true
```

## Notes

- Signatures are stored as PNG files on S3 hosted by the platform
- The canvas cannot be pre-populated or pre-filled via URL parameters
- Touch events are supported, making the field usable on mobile devices
