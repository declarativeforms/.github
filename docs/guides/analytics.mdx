---
title: Track Completions
description: Measure form starts and completions with Mixpanel.
---

Declarative Forms has native Mixpanel support. Add your project token to `rental.yaml` and the platform starts firing events automatically — no SDK to install, no custom code.

---

## What to add

Add the `mixpanel` key at the root of `rental.yaml`:

```yaml
mixpanel: "your-project-token"
```

Replace `your-project-token` with the token from your Mixpanel project settings.

---

## Events fired

| Event | When | Properties |
|-------|------|------------|
| `page_view` | When the form URL is loaded | `form_id` |
| `section_completed` | When each section is submitted | `form_id`, `section_id` |

`form_id` is the filename without the `.yaml` extension — `rental` for `rental.yaml`. `section_id` matches the `id` of the section that was submitted.

You can use these events in Mixpanel to build funnels, measure drop-off between sections, and track overall completion rates.

---

## Complete `rental.yaml`

```yaml
version: 1
title: Rental Application

sections:
  - id: personal
    title: Personal details
    fields:
      - id: full_name
        type: short_text
        label: Full name
        validators:
          - required
      - id: email
        type: email
        label: Email address
        validators:
          - required
      - id: move_in_date
        type: date
        label: Desired move-in date
        validators:
          - required
    next: property

  - id: property
    title: Property details
    fields:
      - id: unit_type
        type: single_select
        label: Unit type
        options:
          - value: studio
            label: Studio
          - value: 1br
            label: 1 bedroom
          - value: 2br
            label: 2 bedrooms
          - value: 3br
            label: 3+ bedrooms
        validators:
          - required
      - id: has_pets
        type: single_select
        label: Do you have pets?
        options:
          - value: "yes"
            label: "Yes"
          - value: "no"
            label: "No"
        validators:
          - required
      - id: pet_details
        type: short_text
        label: Pet details
        placeholder: Breed, size, and number of pets
        visible_when: "data.has_pets === 'yes'"
    next:
      - when: "data.unit_type === 'studio'"
        go: done
      - else: employment

  - id: employment
    title: Employment
    fields:
      - id: employer
        type: short_text
        label: Employer name
        validators:
          - required
      - id: monthly_income
        type: number
        label: Monthly income (USD)
        validators:
          - required
    next: done

connections:
  - type: email
    to: landlord@example.com
    subject: "New application from {{data.full_name}}"
    include_responses: true
  - type: email
    to: "{{data.email}}"
    subject: "Thanks for applying, {{data.full_name}}"
    body: "<p>We received your application and will be in touch within 2 business days.</p>"
  - type: webhook
    url: https://your-api.com/webhooks/rental
  - type: airtable
    connection_id: your-connection-id
    base_id: appXXXXXXXXXXXXXX
    table_id_or_name: Applications

mixpanel: "your-mixpanel-token"

completion:
  title: "Thanks, {{data.full_name}}!"
  message: We'll review your application and be in touch within 2 business days.
```

This is the complete `rental.yaml` — every feature from across the Guides section in one file.
