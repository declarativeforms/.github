title: Capture a Signature
description: Add a signature pad for applicants to sign digitally.
---

The `signature` field in the references section lets applicants sign the rental application digitally before submitting.

---

## What to add

Add a `signature` field to the `references` section of `rental.yaml`:

```yaml
      - id: signature
        type: signature
        label: Signature
        validators:
          - required
```

---

## How it works

`signature` renders a drawing canvas. The applicant draws their signature with a mouse or finger. When the section is submitted, the signature is captured as an image.

**Submission value type:** `string` — a base64-encoded PNG data URL of the signature drawing.

### Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier within the form. |
| `type` | `"signature"` | Yes | Must be `signature`. |
| `label` | `string \| LocaleMap` | Yes | Label shown above the signature pad. |
| `validators` | `Validator[]` | No | Only `required` is supported. |
| `visible_when` | `string` | No | JS expression; field shown when truthy. |
