---
title: Customize the Thank-You Page
description: Show a personalized message after submission completes.
---

After the final section is submitted, the form shows a thank-you screen. Adding a `completion` block to `rental.yaml` lets you customize the heading, body, and call-to-action button — including applicant data via `{{data.fieldId}}` templates.

---

## What to add

Add a `completion` block at the root level of `rental.yaml`:

```yaml
completion:
  title: "Thanks, {{data.full_name}}!"
  message: We'll review your application and be in touch within 2 business days.
  button:
    label: Back to our site
    url: https://example.com
```

---

## How it works

`completion.title` and `completion.message` support `{{data.fieldId}}` template syntax — field values from the completed submission are interpolated at display time. In this example, `{{data.full_name}}` resolves to whatever the applicant typed in the `full_name` field.

`completion.button` adds a CTA button below the message. The `url` also supports template syntax, so you can redirect to a personalized URL if needed.

All three properties — `title`, `message`, and `button.label` — support locale maps for multilingual forms. See [Reach Anyone in Their Language](/guides/localization) for how locale maps work.

### Properties

| Property | Type | Description |
|----------|------|-------------|
| `title` | `string \| LocaleMap` | Thank-you page heading. Supports `{{data.fieldId}}`. |
| `message` | `string \| LocaleMap` | Body text below the heading. Supports `{{data.fieldId}}`. |
| `button.label` | `string \| LocaleMap` | CTA button label. |
| `button.url` | `string` | CTA button URL. Supports `{{data.fieldId}}`. |
