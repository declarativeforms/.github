---
title: Build a Contact Form with Webhook Integration
description: Create a contact form that sends each submission to an external URL via webhook.
---

You'll build a contact form that collects a name, email, and message, then POSTs each submission as JSON to a webhook URL. By the end you'll understand how the `webhook` connection type lets you push form data to any external service — a CRM, a Slack channel, or your own backend.

---

## Define the form

Create a file called `contact_form.yaml` in your repository:

```yaml
version: 1
title: Contact Us
description: Get in touch — we'd love to hear from you.

sections:
  - id: contact
    title: Your Details
    fields:
      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required

      - id: message
        type: long_text
        label: Message
        placeholder: How can we help?
        validators:
          - required
    next: done

connections:
  - type: webhook
    url: https://example.com/webhook
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add contact_form.yaml
git commit -m "add contact form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/contact_form
```

(The `.yaml` extension is not included in the URL.)
