---
title: Build an Invite Form with Pattern Validation
description: Create an invite-only signup form that validates an invite code against a regex pattern.
---

You'll build an invite-only signup form where users enter a name, email, and an invite code that must match a specific format. By the end you'll understand how the `pattern` validator lets you test any field's value against a regular expression using `regex` and a custom `message`.

---

## Define the form

Create a file called `invite.yaml` in your repository:

```yaml
version: 1
title: Invite-Only Signup
description: Enter your invite code to create an account.

sections:
  - id: signup
    title: Your Details
    fields:
      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required

      - id: invite_code
        type: short_text
        label: Invite Code
        placeholder: INV-1234
        validators:
          - required
          - type: pattern
            regex: "^INV-[0-9]{4}$"
            message: Enter a valid invite code (e.g. INV-1234).
    next: done
```

The `pattern` validator accepts two properties: `regex` is the regular expression to test against, and `message` is the error shown when the value doesn't match. If you omit `message`, the form displays a default error using the field label.

---

## Deploy it

Commit and push the file to your repository:

```bash
git add invite.yaml
git commit -m "add invite form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/invite
```

(The `.yaml` extension is not included in the URL.)
