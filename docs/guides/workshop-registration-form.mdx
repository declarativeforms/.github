---
title: "Build a Workshop Registration Form with Airtable Integration"
description: Build a workshop registration form that saves submissions directly to an Airtable base.
---

You'll build a workshop registration form that collects attendee details and writes each submission as a row in an Airtable table. You'll learn how to use the `airtable` connection type.

---

## Define the form

Create a file called `workshop_registration.yaml` in your repository:

```yaml
version: 1
title: Workshop Registration
description: Register for our upcoming workshop.

sections:
  - id: registration
    title: Your Details
    fields:
      - id: name
        type: short_text
        label: Full Name
        validators:
          - required
      - id: email
        type: email
        label: Email Address
        placeholder: you@example.com
        validators:
          - required
      - id: session
        type: dropdown
        label: Session
        options:
          - Morning (9 AM)
          - Afternoon (1 PM)
        validators:
          - required
    next: done

connections:
  - type: airtable
    connection_id: your_connection_id
    base_id: appXXXXXXXXXXXXXX
    table_id_or_name: Registrations
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add workshop_registration.yaml
git commit -m "add workshop registration form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/workshop_registration
```

(The `.yaml` extension is not included in the URL.)
