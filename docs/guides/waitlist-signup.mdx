---
title: Build a Waitlist Signup with a Custom Completion Screen
description: Create a waitlist signup that shows a personalized thank-you message after submission.
---

You'll build a waitlist signup form that collects a name and email, then displays a personalized completion screen with the user's name and a link to your website. By the end you'll understand how the `completion` property customizes the thank-you page with a `title`, `message`, and optional `button`, and how `{{data.fieldId}}` inserts submitted values into the text.

---

## Define the form

Create a file called `waitlist.yaml` in your repository:

```yaml
version: 1
title: Join the Waitlist
description: Be the first to know when we launch.

sections:
  - id: waitlist
    title: Your Details
    fields:
      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required
    next: done

completion:
  title: "You're on the list, {{data.name}}!"
  message: "We'll notify {{data.email}} as soon as we launch."
  button:
    label: Visit our website
    url: https://example.com
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add waitlist.yaml
git commit -m "add waitlist signup form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/waitlist
```

(The `.yaml` extension is not included in the URL.)
