---
title: Conditional Navigation
description: Route section flow with the `next` property.
---

`next` controls which step runs after a section is submitted.

## `next: done`

```yaml
version: 1
title: Example
sections:
  - id: section_1
    title: Start
    fields:
      - id: email
        type: email
        label: Email
    next: done
```

## `next: <section_id>`

```yaml
version: 1
title: Example
sections:
  - id: section_1
    title: Start
    fields:
      - id: full_name
        type: short_text
        label: Full name
    next: section_2

  - id: section_2
    title: Follow up
    fields:
      - id: notes
        type: long_text
        label: Notes
    next: done
```

## `next: https://...`

```yaml
version: 1
title: Example
sections:
  - id: section_1
    title: Start
    fields:
      - id: email
        type: email
        label: Email
    next: https://example.com/thank-you
```

An `https://` value is treated as an external redirect target.

## Conditional rules (`when` / `go` / `else`)

```yaml
version: 1
title: Example
sections:
  - id: section_1
    title: Start
    fields:
      - id: wants_callback
        type: single_select
        label: Would you like a callback?
        options:
          - Yes
          - No
        validators:
          - required
    next:
      - when: data.wants_callback == "Yes"
        go: callback_details
      - else: done

  - id: callback_details
    title: Callback Details
    fields:
      - id: phone
        type: mobile_number
        label: Phone number
        validators:
          - required
    next: done
```

`when` expressions evaluate against `data`, where field values are available as `data.<field_id>`.

## Default behavior when no rule matches

If `next` is a rule list and no `when` condition matches, flow defaults to `done` unless an `else` rule is present.
