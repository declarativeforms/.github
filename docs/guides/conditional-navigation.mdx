---
title: Conditional Navigation
description: Route section flow with the `next` property.
---

`next` controls which step runs after a section is submitted.

## `next: done`

```yaml
version: 1
title: Bug Report Triage
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
      - id: reporter_email
        type: email
        label: Reporter email
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
    next: done
```

## `next: <section_id>`

```yaml
version: 1
title: Bug Report Triage
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
      - id: reporter_email
        type: email
        label: Reporter email
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
    next: section_2

  - id: section_2
    title: Reproduction Details
    fields:
      - id: reproduction_steps
        type: long_text
        label: Reproduction steps
    next: done
```

## `next: https://...`

```yaml
version: 1
title: Bug Report Triage
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
      - id: reporter_email
        type: email
        label: Reporter email
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
    next: https://yourcompany.com/thanks
```

An `https://` value is treated as an external redirect target.

## Conditional rules (`when` / `go` / `else`)

```yaml
version: 1
title: Bug Report Triage
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
      - id: reporter_email
        type: email
        label: Reporter email
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
        validators:
          - required
    next:
      - when: data.severity == "High"
        go: section_2
      - else: done

  - id: section_2
    title: Reproduction Details
    fields:
      - id: reproduction_steps
        type: long_text
        label: Reproduction steps
        validators:
          - required
    next: done
```

`when` expressions evaluate against `data`, where field values are available as `data.<field_id>`.

## Default behavior when no rule matches

If `next` is a rule list and no `when` condition matches, flow defaults to `done` unless an `else` rule is present.
