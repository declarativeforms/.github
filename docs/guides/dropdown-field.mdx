---
title: Use a Searchable Dropdown
description: Offer a collapsible single-selection menu with optional search.
---

The `neighborhood` field in the property section uses a `dropdown` with search enabled — ideal when you have enough options that a radio button list would feel cluttered.

---

## What to add

Add a `dropdown` field to the `property` section of `rental.yaml`:

```yaml
      - id: neighborhood
        type: dropdown
        label: Preferred neighborhood
        searchable: true
        options:
          - value: downtown
            label: Downtown
          - value: midtown
            label: Midtown
          - value: uptown
            label: Uptown
          - value: suburbs
            label: Suburbs
        validators:
          - required
```

---

## How it works

`dropdown` renders a collapsible menu. The applicant clicks to open it and picks exactly one option. Functionally equivalent to `single_select`, but rendered as a dropdown — better for 7+ options or when vertical space is limited.

Setting `searchable: true` adds a text filter inside the dropdown. As the applicant types, options are filtered to match. This is especially useful for long lists like cities or countries.

**Submission value type:** `string` — the `value` of the selected option.

See [reference/dropdown](/reference/dropdown) for full details including localized options.
