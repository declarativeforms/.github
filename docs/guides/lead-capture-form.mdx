---
title: Build a Lead Capture Form with a Hidden Field
description: Create a lead capture form that tracks the referral source in a hidden field populated from the URL.
---

You'll build a lead capture form with a hidden field that records where the lead came from. By the end you'll understand how `type: hidden` creates a field with no visible UI whose value is set through URL query parameters.

---

## Define the form

Create a file called `lead_capture.yaml` in your repository:

```yaml
version: 1
title: Lead Capture
description: Get in touch and we'll follow up.

sections:
  - id: lead
    title: Your Details
    fields:
      - id: source
        type: hidden

      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required

      - id: company
        type: short_text
        label: Company
        placeholder: Acme Inc.
    next: done
```

The `source` field has no label and nothing is rendered on screen. To set its value, add a query parameter whose key matches the field `id`:

```
https://app.declarativeforms.com/<organization>/<repository>/lead_capture?source=homepage-banner
```

When the form is submitted, the `source` value is included in the submission data alongside the visible fields. This lets you embed the same form URL in different campaigns and track which one generated each lead.

---

## Deploy it

Commit and push the file to your repository:

```bash
git add lead_capture.yaml
git commit -m "add lead capture form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/lead_capture
```

(The `.yaml` extension is not included in the URL.)
