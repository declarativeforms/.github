---
title: Translate a form
description: How to make a form available in multiple languages
---

Declarative Forms supports English and Spanish. You can translate any form by providing locale maps for text fields in your YAML.

## Supported locales

| Code | Language |
|------|----------|
| `en` | English |
| `es` | Spanish |

## Step 1 — Replace plain strings with locale maps

Anywhere a text value is accepted, you can replace the string with an object keyed by locale code:

```yaml
# Before
title: Contact Us

# After
title:
  en: Contact Us
  es: Contáctanos
```

## Step 2 — Translate all user-visible text

Translate each text-bearing field in your YAML:

```yaml
version: 1
title:
  en: Contact Us
  es: Contáctanos
description:
  en: We'll get back to you within 24 hours.
  es: Te responderemos en 24 horas.

sections:
  - id: main
    title:
      en: Your message
      es: Tu mensaje
    fields:
      - id: name
        type: short_text
        label:
          en: Full name
          es: Nombre completo
        placeholder:
          en: Jane Smith
          es: Juan García
        validators:
          - required

      - id: email
        type: email
        label:
          en: Email address
          es: Correo electrónico
        validators:
          - required
          - type: pattern
            regex: "^[^@]+@[^@]+\\.[^@]+$"
            message:
              en: Please enter a valid email address.
              es: Por favor ingresa un correo electrónico válido.

      - id: message
        type: long_text
        label:
          en: Message
          es: Mensaje
        validators:
          - required
    next: done

completion:
  title:
    en: "Thanks, {{data.name}}!"
    es: "¡Gracias, {{data.name}}!"
  message:
    en: We'll be in touch soon.
    es: Nos pondremos en contacto pronto.
```

## Step 3 — Lock the form locale (optional)

To force all users to a specific locale, set the top-level `locale` key:

```yaml
locale: es
```

This sets Spanish as the default and updates the URL to include `?lang=es` when users navigate between sections.

## How users switch languages

The active locale is determined in this priority order:

1. `?lang=` query parameter
2. Browser's `navigator.language`
3. `locale` key in the YAML
4. English (`en`) as the final fallback

To link to the Spanish version of your form:

```
https://app.declarativeforms.com/acme/forms/contact?lang=es
```

## Fields that support locale maps

- Form `title` and `description`
- Section `title`
- Field `label`, `placeholder`
- Validator `message`
- Option `label` (for dropdown, single_select, multiple_select, rating)
- `completion.title`, `completion.message`, `completion.button.label`, `completion.button.url`

See [Multilingual options](/guides/multilingual-options) for how to translate dropdown and select options.
