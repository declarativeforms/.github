---
title: Build a Job Application Form with File Uploads
description: Create a job application form that accepts a resume upload with a file count limit.
---

You'll build a job application form where candidates enter their details and upload a resume. By the end you'll understand how `type: file_upload` adds file attachment fields and how the `max` validator limits the number of uploaded files.

---

## Define the form

Create a file called `job_application.yaml` in your repository:

```yaml
version: 1
title: Job Application
description: Apply for a position — fill in your details and upload your resume.

sections:
  - id: application
    title: Your Application
    fields:
      - id: name
        type: short_text
        label: Full name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required

      - id: phone
        type: mobile_number
        label: Phone number
        placeholder: "+1 555 000 0000"

      - id: cover_letter
        type: long_text
        label: Cover letter
        placeholder: Tell us why you're a great fit for this role.
        validators:
          - required

      - id: resume
        type: file_upload
        label: Resume
        validators:
          - required
          - type: max
            value: 5
            message: You can upload up to 5 files.
    next: done
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add job_application.yaml
git commit -m "add job application form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/job_application
```

(The `.yaml` extension is not included in the URL.)
