---
title: Build a Referral Form with URL Prefill
description: Create a referral form that pre-populates fields from URL query parameters.
---

You'll build a referral form where the referrer's name is pre-filled from the URL, so the person being referred only fills in their own details. By the end you'll understand how any query parameter that isn't reserved (`connection_id`, `lang`, `submission_id`, `step`) becomes an initial field value matched by field `id`.

---

## Define the form

Create a file called `referral.yaml` in your repository:

```yaml
version: 1
title: Referral Form
description: Know someone who'd be a great fit? Send them this link.

sections:
  - id: referral
    title: Referral Details
    fields:
      - id: referred_by
        type: short_text
        label: Referred by
        placeholder: Jane Smith
        validators:
          - required

      - id: name
        type: short_text
        label: Your Name
        placeholder: Alex Johnson
        validators:
          - required

      - id: email
        type: email
        label: Your Email
        placeholder: alex@example.com
        validators:
          - required

      - id: reason
        type: long_text
        label: Why are you interested?
        placeholder: Tell us a bit about yourself.
    next: done
```

To prefill the referrer's name, append it as a query parameter whose key matches the field `id`:

```
https://app.declarativeforms.com/<organization>/<repository>/referral?referred_by=Jane+Smith
```

When the form loads, the `referred_by` field will already contain "Jane Smith". The visitor can still edit it, but in most cases it saves them a step. You can prefill any combination of fields this way — for example, adding `&email=alex@example.com` would also prefill the email.

---

## Deploy it

Commit and push the file to your repository:

```bash
git add referral.yaml
git commit -m "add referral form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/referral
```

(The `.yaml` extension is not included in the URL.)
