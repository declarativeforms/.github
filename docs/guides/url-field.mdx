The `website` field in the personal section lets applicants share a personal website or LinkedIn profile.

---

## What to add

Add a `url` field to the `personal` section of `rental.yaml`:

```yaml
      - id: website
        type: url
        label: Personal website or LinkedIn
```

---

## How it works

`url` renders a text input that validates the entered value as a correctly formatted URL before the section is submitted. The input must start with `http://` or `https://`.

**Submission value type:** `string` — the URL as entered by the applicant.

This field is optional in the rental form (no `required` validator). Making a URL field optional is common when you want to give applicants the option to provide additional context without requiring it.

### Validators

| Validator | Description |
|-----------|-------------|
| `required` | A valid URL must be entered. |
