---
title: Build a Country Selector Form with a Searchable Dropdown
description: Create a country selector form with a searchable dropdown that lets users filter options by typing.
---

You'll build a country selector form where users pick their country from a long dropdown list they can filter by typing. By the end you'll understand how `type: dropdown` renders a select menu and how adding `searchable: true` switches it to a combobox that filters options as the user types.

---

## Define the form

Create a file called `country_selector.yaml` in your repository:

```yaml
version: 1
title: Select Your Country
description: Tell us where you're based.

sections:
  - id: location
    title: Your Location
    fields:
      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: country
        type: dropdown
        label: Country
        searchable: true
        options:
          - Argentina
          - Australia
          - Brazil
          - Canada
          - China
          - France
          - Germany
          - India
          - Italy
          - Japan
          - Mexico
          - Netherlands
          - South Africa
          - South Korea
          - Spain
          - Sweden
          - United Kingdom
          - United States
        validators:
          - required
    next: done
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add country_selector.yaml
git commit -m "add country selector form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/country_selector
```

(The `.yaml` extension is not included in the URL.)
