title: Add a Date Picker
description: Collect a date with a calendar picker.
---

The `move_in_date` field in the personal section collects the applicant's desired move-in date using a calendar picker.

---

## What to add

Add a `date` field to the `personal` section of `rental.yaml`:

```yaml
      - id: move_in_date
        type: date
        label: Desired move-in date
        validators:
          - required
```

---

## How it works

`date` renders a calendar date picker. The applicant selects a date; no free-form text entry is allowed.

**Submission value type:** `string` in ISO 8601 format — `"2025-03-15"`.

### Validators

| Validator | Description |
|-----------|-------------|
| `required` | A date must be selected. |
| `type: min` + `value` | Earliest allowed date (ISO 8601 string). |
| `type: max` + `value` | Latest allowed date (ISO 8601 string). |

Example: restrict move-in dates to within a specific window:

```yaml
        validators:
          - required
          - type: min
            value: "2025-01-01"
          - type: max
            value: "2025-12-31"
```
