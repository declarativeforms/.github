---
title: Build a Feedback Form with Email Notification
description: Create a feedback form that emails you whenever someone submits a response.
---

You'll build a feedback form that sends an email notification whenever someone submits. By the end you'll understand how `connections` lets you react to submissions — in this case by sending a formatted email with the respondent's answers.

---

## Define the form

Create a file called `feedback.yaml` in your repository:

```yaml
version: 1
title: Feedback
description: We'd love to hear from you — share your thoughts below.

sections:
  - id: feedback
    title: Your Feedback
    fields:
      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required

      - id: message
        type: long_text
        label: Your feedback
        placeholder: What went well? What could be better?
        validators:
          - required
    next: done

connections:
  - type: email
    to: team@example.com
    subject: "New feedback from {{data.name}}"
    body: |
      <p>You received new feedback.</p>
      <p><strong>From:</strong> {{data.name}} ({{data.email}})</p>
      <p><strong>Message:</strong></p>
      <p>{{data.message}}</p>
    include_responses: true
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add feedback.yaml
git commit -m "add feedback form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/feedback
```

(The `.yaml` extension is not included in the URL.)
