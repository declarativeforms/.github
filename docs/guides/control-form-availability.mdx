---
title: Control form availability
description: How to set open and close dates for a form
---

Use `start_date` and `end_date` to control when a form is accessible. Visitors who arrive outside the window see a message instead of the form.

## Configuration

```yaml
version: 1
title: Early Access Signup
start_date: "2025-09-01"
end_date: "2025-09-30"

sections:
  - id: main
    fields:
      - id: email
        type: email
        label: Email address
    next: done
```

Both keys are optional. You can use either, both, or neither.

## `start_date`

The form is **not accessible before** this date. Visitors who arrive early see a "not yet open" message.

```yaml
start_date: "2025-09-01"
```

## `end_date`

The form is **not accessible after** this date. Visitors who arrive late see a "form closed" message.

```yaml
end_date: "2025-09-30"
```

## Date format

Both keys accept ISO 8601 date strings. You can use:

- Date only: `"2025-09-01"` (interpreted as midnight UTC)
- Date and time: `"2025-09-01T09:00:00Z"` (with explicit timezone)

## Use cases

| Scenario | Configuration |
|----------|---------------|
| Event registration (opens on a date) | `start_date` only |
| Limited-time survey (closes on a date) | `end_date` only |
| Timed application window | Both `start_date` and `end_date` |

## Full example: conference registration

```yaml
version: 1
title: Conference Registration
description: Register for the Annual Developer Conference 2025.
start_date: "2025-08-01"
end_date: "2025-10-15"

sections:
  - id: registration
    title: Your details
    fields:
      - id: name
        type: short_text
        label: Full name
        validators:
          - required
      - id: email
        type: email
        label: Email address
        validators:
          - required
      - id: ticket
        type: single_select
        label: Ticket type
        options: [General Admission, VIP, Student]
        validators:
          - required
    next: done

connections:
  - type: email
    to: "{{data.email}}"
    subject: "Your registration is confirmed, {{data.name}}!"
    body: "<p>We look forward to seeing you at the conference.</p>"
```

## Notes

- Availability is checked when the form page loads, not at submission time
- There is no UI for setting dates—they are set in YAML and take effect immediately on push
- Dates in YAML are parsed in the server's timezone unless an explicit timezone offset is included
