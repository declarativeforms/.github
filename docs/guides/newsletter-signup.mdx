---
title: Build a Newsletter Signup
description: Create a two-field newsletter signup form with name and email validation.
---

In this guide you'll build a newsletter signup form with two fields — name and email — both required. By the end you'll understand how `version`, `title`, `description`, `sections`, `fields`, `validators`, and `next` work together.

---

## Define the form

Create a file called `newsletter.yaml` in your repository:

```yaml
version: 1
title: Newsletter Signup
description: Stay in the loop — get updates delivered to your inbox.

sections:
  - id: signup
    title: Your Details
    fields:
      - id: name
        type: short_text
        label: Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required
    next: done
```

---

## Deploy it

Commit and push the file to your repository:

```bash
git add newsletter.yaml
git commit -m "add newsletter signup form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/newsletter
```

(The `.yaml` extension is not included in the URL.)
