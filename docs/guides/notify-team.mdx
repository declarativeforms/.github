---
title: Notify Your Team
description: Send an email when someone submits the form.
---

Once a submission completes, you'll want to know about it. This guide adds two email connections: one that notifies the landlord, and one that confirms receipt to the applicant.

---

## What to add

Add a `connections` block at the root level of `rental.yaml`:

```yaml
connections:
  - type: email
    to: landlord@example.com
    subject: "New application from {{data.full_name}}"
    include_responses: true
  - type: email
    to: "{{data.email}}"
    subject: "Thanks for applying, {{data.full_name}}"
    body: "<p>We received your application and will be in touch within 2 business days.</p>"
```

---

## Connection properties

| Property | Type | Description |
|----------|------|-------------|
| `type` | string | `email` for email connections |
| `to` | string | Recipient address. Supports `{{data.fieldId}}` templates. |
| `subject` | string | Email subject line. Supports `{{data.fieldId}}` templates. |
| `body` | string | HTML email body. Optional. Supports `{{data.fieldId}}` templates. |
| `include_responses` | boolean | When `true`, appends a formatted summary of all submitted fields to the email body. |

---

## Template syntax

Use `{{data.fieldId}}` anywhere in `to`, `subject`, or `body` to interpolate a submitted value. For example:

```
"New application from {{data.full_name}}"
```

renders as:

```
New application from Jordan Lee
```

Templates resolve at send time using the completed submission's data.

---

## When connections fire

Connections fire once when the submission `status` becomes `completed` — that is, when the final section is submitted and `next` resolves to `done`. They do not fire for partial saves (mid-flow section submissions).

## Complete `rental.yaml`

```yaml
version: 1
title: Rental Application

sections:
  - id: personal
    title: Personal details
    fields:
      - id: full_name
        type: short_text
        label: Full name
        validators:
          - required
      - id: email
        type: email
        label: Email address
        validators:
          - required
      - id: move_in_date
        type: date
        label: Desired move-in date
        validators:
          - required
    next: property

  - id: property
    title: Property details
    fields:
      - id: unit_type
        type: single_select
        label: Unit type
        options:
          - value: studio
            label: Studio
          - value: 1br
            label: 1 bedroom
          - value: 2br
            label: 2 bedrooms
          - value: 3br
            label: 3+ bedrooms
        validators:
          - required
      - id: has_pets
        type: single_select
        label: Do you have pets?
        options:
          - value: "yes"
            label: "Yes"
          - value: "no"
            label: "No"
        validators:
          - required
      - id: pet_details
        type: short_text
        label: Pet details
        placeholder: Breed, size, and number of pets
        visible_when: "data.has_pets === 'yes'"
    next:
      - when: "data.unit_type === 'studio'"
        go: done
      - else: employment

  - id: employment
    title: Employment
    fields:
      - id: employer
        type: short_text
        label: Employer name
        validators:
          - required
      - id: monthly_income
        type: number
        label: Monthly income (USD)
        validators:
          - required
    next: done

connections:
  - type: email
    to: landlord@example.com
    subject: "New application from {{data.full_name}}"
    include_responses: true
  - type: email
    to: "{{data.email}}"
    subject: "Thanks for applying, {{data.full_name}}"
    body: "<p>We received your application and will be in touch within 2 business days.</p>"
```
