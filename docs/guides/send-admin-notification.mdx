---
title: Send an admin notification email
description: How to notify your team when a form is submitted
---

Add an `email` connection with a static recipient address to notify your team whenever a form is submitted.

## Configuration

```yaml
connections:
  - type: email
    to: team@example.com
    subject: New form submission
    include_responses: true
```

Set `include_responses: true` to automatically include all non-hidden field responses as a formatted HTML table in the email.

## Custom body

You can include a custom HTML body alongside the responses table:

```yaml
connections:
  - type: email
    to: team@example.com
    subject: "New submission from {{data.name}}"
    body: "<p>A new submission was received. See responses below.</p>"
    include_responses: true
```

## Multiple recipients

Send to multiple people by adding multiple email connections:

```yaml
connections:
  - type: email
    to: sales@example.com
    subject: New lead submitted
    include_responses: true

  - type: email
    to: manager@example.com
    subject: "New lead: {{data.company_name}}"
    body: "<p>A new lead from {{data.name}} at {{data.company_name}} requires your review.</p>"
```

## Combining with a user confirmation

You can have both a user confirmation and an admin notification in the same form:

```yaml
connections:
  # Confirmation to user
  - type: email
    to: "{{data.email}}"
    subject: "Thanks for reaching out, {{data.name}}!"
    body: "<p>We'll be in touch within 24 hours.</p>"

  # Admin notification
  - type: email
    to: support@example.com
    subject: "New contact form submission from {{data.name}}"
    include_responses: true
```

## Notes

- Email connections fire **only on final submission**
- If `body` is omitted and `include_responses` is false, the email body defaults to the rendered `subject`
- Hidden fields are excluded from the `include_responses` table
- Emails are sent via [Resend](https://resend.com)
