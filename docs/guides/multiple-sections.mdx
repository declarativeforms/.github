---
title: Multiple Sections
description: Split a form into more than one section using explicit section IDs and `next` routing.
---

Use multiple sections when you want the form to progress step by step.

## Single section baseline

```yaml
version: 1
title: Bug Report Triage
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
        validators:
          - required
      - id: reporter_email
        type: email
        label: Reporter email
        validators:
          - required
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
        validators:
          - required
    next: done
```

## Add a second section

Change `section_1.next` from `done` to the next section ID.

```yaml
version: 1
title: Bug Report Triage
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
        validators:
          - required
      - id: reporter_email
        type: email
        label: Reporter email
        validators:
          - required
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
        validators:
          - required
    next: section_2

  - id: section_2
    title: Reproduction Details
    fields:
      - id: reproduction_steps
        type: long_text
        label: Reproduction steps
        validators:
          - required
    next: done
```

## Rules

- Each section needs a unique `id`
- Use `next: <section_id>` to continue to another section
- Use `next: done` to finish the form
