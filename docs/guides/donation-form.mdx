---
title: Build a Donation Form with a Number Field
description: Create a donation form that collects a whole-number amount using the number field type.
---

You'll build a donation form where supporters enter their name, email, and a donation amount as a whole number. By the end you'll understand how `type: number` renders a numeric input that only accepts whole numbers.

---

## Define the form

Create a file called `donation.yaml` in your repository:

```yaml
version: 1
title: Donation Form
description: Support our cause — every contribution counts.

sections:
  - id: donation
    title: Make a Donation
    fields:
      - id: name
        type: short_text
        label: Full Name
        placeholder: Jane Smith
        validators:
          - required

      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required

      - id: amount
        type: number
        label: Donation Amount (USD)
        placeholder: "50"
        validators:
          - required
    next: done
```

The `number` field displays a text input with a numeric keyboard on mobile devices. It only accepts whole numbers — if a visitor enters letters or a decimal, the form shows a validation error.

---

## Deploy it

Commit and push the file to your repository:

```bash
git add donation.yaml
git commit -m "add donation form"
git push
```

Then open your form at:

```
https://app.declarativeforms.com/<organization>/<repository>/donation
```

(The `.yaml` extension is not included in the URL.)
