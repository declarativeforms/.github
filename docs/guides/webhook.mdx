---
title: Send to Your Back End
description: POST every submission to an endpoint you control.
---

A webhook connection sends completed submission data to any URL you specify. Use it to trigger downstream logic — creating a record in your database, kicking off a workflow, or notifying a service that doesn't have a native integration.

---

## What to add

Add a webhook entry to the `connections` block:

```yaml
connections:
  - type: webhook
    url: https://your-api.com/webhooks/rental
```

---

## Payload shape

When a submission completes, the platform sends a `POST` request to the configured URL with a JSON body:

```json
{
  "submission_id": "sub_abc123",
  "form_id": "rental",
  "status": "completed",
  "submitted_at": "2024-11-15T14:32:00Z",
  "data": {
    "full_name": "Jordan Lee",
    "email": "jordan@example.com",
    "move_in_date": "2025-01-01",
    "unit_type": "1br",
    "has_pets": "yes",
    "pet_details": "1 golden retriever, medium size",
    "employer": "Acme Corp",
    "monthly_income": 6500
  }
}
```

`data` contains only the fields that were submitted. Hidden fields (those whose `visible_when` evaluated to false) are omitted.

---

## Authentication

No authentication header is sent by default. To secure your endpoint:

- Embed a secret token in the URL (e.g., `https://your-api.com/webhooks/rental?token=abc123`) and validate it in your handler.
- Or verify the `submission_id` by fetching it from the Declarative Forms API in your handler.

---

## Timing

The webhook fires once when `status` becomes `completed`. It does not fire for partial saves.

## Complete `rental.yaml`

```yaml
version: 1
title: Rental Application

sections:
  - id: personal
    title: Personal details
    fields:
      - id: full_name
        type: short_text
        label: Full name
        validators:
          - required
      - id: email
        type: email
        label: Email address
        validators:
          - required
      - id: move_in_date
        type: date
        label: Desired move-in date
        validators:
          - required
    next: property

  - id: property
    title: Property details
    fields:
      - id: unit_type
        type: single_select
        label: Unit type
        options:
          - value: studio
            label: Studio
          - value: 1br
            label: 1 bedroom
          - value: 2br
            label: 2 bedrooms
          - value: 3br
            label: 3+ bedrooms
        validators:
          - required
      - id: has_pets
        type: single_select
        label: Do you have pets?
        options:
          - value: "yes"
            label: "Yes"
          - value: "no"
            label: "No"
        validators:
          - required
      - id: pet_details
        type: short_text
        label: Pet details
        placeholder: Breed, size, and number of pets
        visible_when: "data.has_pets === 'yes'"
    next:
      - when: "data.unit_type === 'studio'"
        go: done
      - else: employment

  - id: employment
    title: Employment
    fields:
      - id: employer
        type: short_text
        label: Employer name
        validators:
          - required
      - id: monthly_income
        type: number
        label: Monthly income (USD)
        validators:
          - required
    next: done

connections:
  - type: email
    to: landlord@example.com
    subject: "New application from {{data.full_name}}"
    include_responses: true
  - type: email
    to: "{{data.email}}"
    subject: "Thanks for applying, {{data.full_name}}"
    body: "<p>We received your application and will be in touch within 2 business days.</p>"
  - type: webhook
    url: https://your-api.com/webhooks/rental
```
