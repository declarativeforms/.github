Declarative Forms is a hosted form platform where the entire form definition lives in a YAML file in your GitHub repository. There is no visual editor, no separate admin panel, and no proprietary config format — just a file you can read, edit, review, and version like any other code.

## Why this approach

**Version control.** Every change to a form is a commit. You can see exactly what changed, when, and why — the same way you track changes to application code.

**Code review.** Adding a field, changing a label, or rewording a validation message goes through a pull request. Your team reviews it before it goes live.

**No visual editor.** Visual editors feel fast at first, but they hide structure and make collaboration harder. A YAML file is readable by anyone and editable anywhere.

## The 48-hour promise

Open a [GitHub Issue](https://github.com/declarativeforms/examples/issues) with a feature request — if it genuinely improves the product, we'll ship it within 48 hours.
