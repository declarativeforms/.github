---
title: Quickstart
description: Build and publish a simple bug report triage form in minutes.
---

This is the fastest path to a live form.

## 1. Create `bug_report.yaml`

```yaml
version: 1
title: Bug Report Triage
description: Basic bug intake
sections:
  - id: section_1
    title: Bug Details
    fields:
      - id: bug_title
        type: short_text
        label: Bug title
        placeholder: Login button is unresponsive
        validators:
          - required
      - id: reporter_email
        type: email
        label: Reporter email
        placeholder: dev@example.com
        validators:
          - required
      - id: severity
        type: single_select
        label: Severity
        options:
          - Low
          - Medium
          - High
        validators:
          - required
    next: done
```

This demonstrates the core model: one YAML file defines the full form.

## 2. Push to GitHub

Push the file to the `main` branch of a public repository.

```bash
git add bug_report.yaml
git commit -m "Add bug report triage form"
git push origin main
```

## 3. Open your live form

`https://app.declarativeforms.com/{owner}/{repository}/bug_report`

Replace `{owner}` and `{repository}` with your GitHub namespace and repository name.
