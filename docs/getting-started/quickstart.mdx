---
title: Quickstart
description: Build and publish a simple rental application form in minutes.
---

This is the fastest path to a live form.

## 1. Create `rental_application.yaml`

```yaml
version: 1
title: Rental Application
description: Basic renter details
sections:
  - id: section_1
    title: Applicant
    fields:
      - id: full_name
        type: short_text
        label: Full name
        placeholder: Jane Doe
        validators:
          - required
      - id: email
        type: email
        label: Email
        placeholder: jane@example.com
        validators:
          - required
      - id: move_in_timeline
        type: single_select
        label: Move-in timeline
        options:
          - Immediately
          - Within 30 days
          - Within 60 days
        validators:
          - required
    next: done
```

This demonstrates the core model: one YAML file defines the full form.

## 2. Push to GitHub

Push the file to the `main` branch of a public repository.

```bash
git add rental_application.yaml
git commit -m "Add rental application form"
git push origin main
```

## 3. Open your live form

`https://app.declarativeforms.com/{owner}/{repository}/rental_application`

Replace `{owner}` and `{repository}` with your GitHub namespace and repository name.
