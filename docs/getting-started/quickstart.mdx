By the end of this page you will have a live form URL using only a public GitHub repository.

---

## Step 1 - Create your form file

Create `intake.yaml` at the root of your repository (or any path). The filename becomes the form name in the URL.

```yaml
version: 1
title: General Intake
description: Tell us what you need and we will follow up.
sections:
  - id: contact
    title: Contact
    fields:
      - id: full_name
        type: short_text
        label: Full name
        validators:
          - required
      - id: email
        type: email
        label: Work email
        validators:
          - required
      - id: request_type
        type: single_select
        label: What do you need?
        options:
          - Sales inquiry
          - Partnership
          - Support
      - id: team_size
        type: dropdown
        label: Team size
        options:
          - 1-10
          - 11-50
          - 51-200
          - 201+
    next: done
```

With this file name, the form path will end in `/intake`.

---

## Step 2 - Push to GitHub

```bash
git add intake.yaml
git commit -m "Add intake form"
git push
```

---

## Step 3 - Open the live form

`https://app.declarativeforms.com/{owner}/{repo}/intake`

Replace `{owner}` and `{repo}` with your GitHub username/org and repository name.

No account required.

---

## Optional - Prefill fields from the URL

Any query parameter that matches a field `id` prefills that field.

`https://app.declarativeforms.com/{owner}/{repo}/intake?request_type=Partnership&team_size=11-50`

Reserved parameters (`connection_id`, `lang`, `submission_id`, `step`) are platform parameters and are not used for field prefill.
