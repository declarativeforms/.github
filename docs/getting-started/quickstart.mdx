## Prerequisites

- A GitHub account
- A repository (public or private)

---

## Step 1 — Create `feedback.yaml`

Create a file named `feedback.yaml` in the root of your repository:

```yaml
version: 1
title: Feedback
sections:
  - id: main
    title: Share your feedback
    fields:
      - id: name
        type: short_text
        label: Your name
      - id: message
        type: short_text
        label: Your message
    next: done
```

This is the minimum valid form: a version number, a title, and one section with two fields.

---

## Step 2 — Push to `main`

```bash
git add feedback.yaml
git commit -m "Add feedback form"
git push
```

---

## Step 3 — Visit your form

```
https://app.declarativeforms.com/{owner}/{repo}/feedback
```

Replace `{owner}` with your GitHub username or organization, and `{repo}` with your repository name. The form is live immediately — no deploy step required.
