By the end of this page you'll have a live form at a real URL. All you need is a public GitHub repository.

---

## Step 1 — Create the YAML file

Create `rental.yaml` at the root of your repository (or any path — the filename becomes the form name):

```yaml
version: 1
title: Rental Application
sections:
  - id: basic_info
    title: Basic info
    fields:
      - id: full_name
        type: short_text
        label: Full name
        validators:
          - required
      - id: email
        type: email
        label: Email address
        validators:
          - required
      - id: unit_type
        type: single_select
        label: Unit type
        options:
          - Studio
          - 1 bedroom
          - 2 bedrooms
        validators:
          - required
    next: done
```

The filename — `rental` — becomes the last segment of your form's URL.

---

## Step 2 — Push to GitHub

```bash
git add rental.yaml
git commit -m "Add rental application form"
git push
```

That's it.

---

## Step 3 — Open your form

```
https://app.declarativeforms.com/{owner}/{repo}/rental
```

Replace `{owner}` and `{repo}` with your GitHub username and repository name. Your form is live — no account required.
