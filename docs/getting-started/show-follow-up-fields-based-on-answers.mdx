---
title: Show follow-up fields based on answers
description: Show extra fields only when they are relevant in a public GitHub repository.
---

Make your form adapt to the person filling it out. By the end of this guide, your form will show a company field only when someone selects a business inquiry, while keeping the same email connection sending completed submissions to you.

Start from the `contact.yaml` form in the first guide and keep it in a public GitHub repository on the `main` branch.

## Start with

Start with the contact form fields without any conditional logic:

```yaml
sections:
  - id: contact
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done
```

In this version, every field is always visible.

## Build it

Add a field that asks what kind of inquiry this is:

```yaml
      - id: inquiry_type
        type: single_select
        label: "What kind of inquiry is this?"
        options:
          - Personal
          - Business
        validators:
          - required
```

Then add a follow-up field that only appears for business inquiries:

```yaml
      - id: company_name
        type: short_text
        label: "Company name"
        placeholder: "Acme Inc."
        visible_when: data.inquiry_type === "Business"
```

When `inquiry_type` is `Business`, the `company_name` field appears. When it is `Personal`, the field stays hidden.

Keep the same email connection:

```yaml
connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

## Final version

Your full `contact.yaml` file should now look like this:

```yaml
version: 1
title: "Contact us"
description: "Send us a message and we will get back to you."

sections:
  - id: contact
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

      - id: inquiry_type
        type: single_select
        label: "What kind of inquiry is this?"
        options:
          - Personal
          - Business
        validators:
          - required

      - id: company_name
        type: short_text
        label: "Company name"
        placeholder: "Acme Inc."
        visible_when: data.inquiry_type === "Business"

      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done

connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

## Try it

Commit the updated `contact.yaml` file to the `main` branch, then open:

`https://frms.dev/<owner>/<repo>/contact`

Replace `<owner>` with your GitHub username or organization, and `<repo>` with your repository name.

Open the form and test both paths. If you select **Personal**, the **Company name** field should stay hidden. If you select **Business**, the **Company name** field should appear. The rest of the form should work the same way, and submitting it should still send the submission email.
