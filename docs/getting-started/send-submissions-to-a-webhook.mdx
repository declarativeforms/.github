---
title: Send submissions to a webhook
description: Send completed form submissions to an external endpoint in a public GitHub repository.
---

Send your form submissions to another system. By the end of this guide, your form will post completed submissions to a webhook URL instead of sending them by email.

Start from the `contact.yaml` form in the first guide and keep it in a public GitHub repository on the `main` branch.

## Start with

Start with the email connection from the first guide:

```yaml
connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

In this version, submissions are sent to an inbox.

## Build it

Replace that connection with a webhook connection:

```yaml
connections:
  - type: webhook
    url: "https://example.com/form-submissions"
```

Replace `https://example.com/form-submissions` with the endpoint that should receive the submission.

## Final version

Your full `contact.yaml` file should now look like this:

```yaml
version: 1
title: "Contact us"
description: "Send us a message and we will get back to you."

sections:
  - id: contact
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        validators:
          - required

      - id: message
        type: long_text
        label: "Message"
        validators:
          - required

    next: done

connections:
  - type: webhook
    url: "https://example.com/form-submissions"
```

## Try it

Commit the updated `contact.yaml` file to the `main` branch, then open:

`https://frms.dev/<owner>/<repo>/contact`

Replace `<owner>` with your GitHub username or organization, and `<repo>` with your repository name.

Open the form and submit it once. The form should complete normally, and your webhook endpoint should receive the submission.
