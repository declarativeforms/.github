---
title: Create your first form
description: Create a practical contact form from a YAML file in a public GitHub repository.
---

Create a contact form that someone can actually use. By the end of this guide, you will have a form with a name field, an email field, a message field, and an email connection that sends new submissions to you.

Use a public GitHub repository and create a root-level file named `contact.yaml` on the `main` branch.

## Start with

Start with the top of the form:

```yaml
version: 1
title: "Contact us"
description: "Send us a message and we will get back to you."
```

This gives your form a title and a short description.

## Build it

Add one section with the three fields most contact forms need:

```yaml
sections:
  - id: contact
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done
```

This creates a single contact form step with three required fields.

Then add a connection so completed submissions are sent to your inbox:

```yaml
connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

Replace `hello@example.com` with the email address where you want to receive new messages.

## Final version

Your full `contact.yaml` file should now look like this:

```yaml
version: 1
title: "Contact us"
description: "Send us a message and we will get back to you."

sections:
  - id: contact
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done

connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

## Try it

Commit `contact.yaml` to the `main` branch, then open:

`https://frms.dev/<owner>/<repo>/contact`

Replace `<owner>` with your GitHub username or organization, and `<repo>` with your repository name. The URL uses the filename without `.yaml`, so `contact.yaml` becomes `contact`.

Open the form and test it once from start to finish. You should see the title, description, and the three fields from your YAML. Clicking **Next** with empty fields should show validation errors. Filling in all fields and clicking **Next** should submit the form and trigger the default thank-you screen.
