---
title: "Create your first form"
description: "Create a contact form in GitHub, open it on frms.dev, and send submissions to your inbox."
---

Create a working contact form in a few steps. You will define it in `contact.yaml`, Declarative Forms will render it from GitHub, and completed submissions will be sent to your inbox.

## Create the form

<Steps>
  <Step title="Create contact.yaml">
    In the root of a public GitHub repository, create a file named `contact.yaml` and keep it on the `main` branch.

    Declarative Forms reads this file from GitHub and renders the form for you.
  </Step>

  <Step title="Add the form details">
    Start the file with the top-level form details:

    ```yaml
    version: 1
    title: "Contact us"
    description: "Send us a message and we will get back to you."
    ```

    This gives the form a title and short description.
  </Step>

  <Step title="Add the contact fields">
    In the same `contact.yaml` file, add one section with the three fields most contact forms need:

    ```yaml
    sections:
      - id: contact
        title: "Your details"
        fields:
          - id: full_name
            type: short_text
            label: "Full name"
            placeholder: "Jane Smith"
            validators:
              - required

          - id: email
            type: email
            label: "Email address"
            placeholder: "jane@example.com"
            validators:
              - required

          - id: message
            type: long_text
            label: "Message"
            placeholder: "How can we help?"
            validators:
              - required

        next: done
    ```

    Add this below the form details. You now have a single-step contact form with three required fields.
  </Step>

  <Step title="Add the email connection">
    Add an email connection so completed submissions are sent to your inbox. Your completed `contact.yaml` file should now look like this:

    ```yaml
    version: 1
    title: "Contact us"
    description: "Send us a message and we will get back to you."

    sections:
      - id: contact
        title: "Your details"
        fields:
          - id: full_name
            type: short_text
            label: "Full name"
            placeholder: "Jane Smith"
            validators:
              - required

          - id: email
            type: email
            label: "Email address"
            placeholder: "jane@example.com"
            validators:
              - required

          - id: message
            type: long_text
            label: "Message"
            placeholder: "How can we help?"
            validators:
              - required

        next: done

    connections:
      - type: email
        to: "hello@example.com"
        subject: "New contact form submission"
        include_responses: true
    ```

    Replace `hello@example.com` with the inbox that should receive new messages.
  </Step>

  <Step title="Open and test the form">
    Commit `contact.yaml` to `main`, then open:

    ```text
    https://frms.dev/<owner>/<repo>/contact
    ```

    Replace `<owner>` with your GitHub username or organization, and `<repo>` with your repository name. The URL uses the filename without `.yaml`, so `contact.yaml` becomes `contact`.

    Open the form and submit a test entry. You should see the title, description, and all three fields. Submitting empty required fields should show validation errors. Submitting a complete form should show the default thank-you screen, and the submission email should arrive in the inbox you configured.
  </Step>
</Steps>
