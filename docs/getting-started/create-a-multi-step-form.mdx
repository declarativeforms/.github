---
title: Create a multi-step form
description: Split a basic contact form into two steps in a public GitHub repository.
---

Turn a one-step contact form into a multi-step form. By the end of this guide, you will have one step for contact details, one step for the message, and the same email connection sending completed submissions to you.

Start from the `contact.yaml` form in the first guide and keep it in a public GitHub repository on the `main` branch.

## Start with

Start with the single-step form structure:

```yaml
sections:
  - id: contact
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done
```

In this version, every field appears in one step.

## Build it

Replace that section with two sections:

```yaml
sections:
  - id: contact_details
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

    next: request

  - id: request
    title: "Your message"
    fields:
      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done
```

This splits the form into two steps. The first step collects contact details. The second step collects the message.

Keep the same email connection:

```yaml
connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

## Final version

Your full `contact.yaml` file should now look like this:

```yaml
version: 1
title: "Contact us"
description: "Send us a message and we will get back to you."

sections:
  - id: contact_details
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        placeholder: "Jane Smith"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        placeholder: "jane@example.com"
        validators:
          - required

    next: request

  - id: request
    title: "Your message"
    fields:
      - id: message
        type: long_text
        label: "Message"
        placeholder: "How can we help?"
        validators:
          - required

    next: done

connections:
  - type: email
    to: "hello@example.com"
    subject: "New contact form submission"
    include_responses: true
```

## Try it

Commit the updated `contact.yaml` file to the `main` branch, then open:

`https://frms.dev/<owner>/<repo>/contact`

Replace `<owner>` with your GitHub username or organization, and `<repo>` with your repository name.

Open the form and test the flow from start to finish. The first step should show **Full name** and **Email address**. Clicking **Next** should move to the second step, which should show **Message**. On the second step, a **Back** button should let you return to the first step. After you submit the final step, the form should complete and send the submission email.
