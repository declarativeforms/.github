# Templating

Form definitions support Handlebars templating to insert dynamic values into user-facing text. Templates reference field values from the current submission.

See also: [Localization](/reference/localization) for localized text (works with templates), [Validation](/reference/validation) for field constraints, [Conditional Logic](/reference/conditional-logic) for expression-driven visibility and navigation.

---

## Syntax

```
{{data.fieldId}}
```

Inserts the current value of the field with the given `id`.

---

## Template context

<ParamField body="data" type="object">
  Contains all current field values, keyed by field `id`. For example, a field with `id: "name"` is accessible as `{{data.name}}`.
</ParamField>

<ParamField body="form" type="object">
  Form metadata. Available **only** within email connections.
</ParamField>

---

## Behavior

- Templates are evaluated with the current submission data.
- No HTML escaping — raw values are inserted.
- If a referenced field has no value, an empty string is inserted.

---

## Where supported

| Location | Properties |
| --- | --- |
| Form | `title`, `description` |
| Section | `title` |
| Field | `label`, `placeholder` |
| Completion | `title`, `message`, `button` (label), `button` (url) |
| Rating field | `min_label`, `max_label` |
| Email connection | `to`, `subject`, `body` |

---

## Examples

### Dynamic labels

```yaml
sections:
  - title: "About You"
    fields:
      - id: "first_name"
        type: "short_text"
        label: "First Name"

      - id: "last_name"
        type: "short_text"
        label: "Last Name"

  - title: "Welcome, {{data.first_name}}"
    fields:
      - id: "role"
        type: "dropdown"
        label: "What best describes you, {{data.first_name}}?"
        options:
          - label: "Developer"
            value: "developer"
          - label: "Designer"
            value: "designer"
```

### Completion message

```yaml
completion:
  title: "Thanks, {{data.first_name}}!"
  message: "We've received your application for the {{data.role}} position."
  button:
    label: "View status"
    url: "https://example.com/status?name={{data.first_name}}+{{data.last_name}}"
```

### Email connection

In email connections, both `data` (field values) and `form` (form metadata) are available in the template context.

```yaml
connections:
  - type: "email"
    to: "{{data.email}}"
    subject: "New submission from {{data.first_name}} {{data.last_name}}"
    body: |
      Name: {{data.first_name}} {{data.last_name}}
      Role: {{data.role}}
      Message: {{data.message}}
```

### Templating with localization

Templates work inside [localized text](/reference/localization) values.

```yaml
completion:
  title:
    en: "Thanks, {{data.first_name}}!"
    es: "¡Gracias, {{data.first_name}}!"
  message:
    en: "Your submission for {{data.role}} has been received."
    es: "Su solicitud para {{data.role}} ha sido recibida."
```
