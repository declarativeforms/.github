---
title: single_select
description: Radio-button selection field for choosing one option from a list.
---

```yaml
- id: plan
  type: single_select

  label: Plan                          # Required. String or localized object.

  options:                             # Required. Array of strings or {label, value} objects.
    - Free                             # String shorthand: label and value are the same.
    - Pro
    - value: enterprise                # Object form: value submitted, label displayed.
      label: Enterprise
    # - value: team                    # Localized label variant:
    #   label:
    #     en: Team
    #     es: Equipo

  # visible_when: data.needs_plan == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. A selection must be made.
```
