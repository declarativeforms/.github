---
title: signature
description: Digital signature pad.
---

`signature` renders a drawing canvas where the applicant can draw their signature with a mouse or finger.

**Submission value type:** `string` — a base64-encoded PNG data URL of the signature drawing.

---

## Field properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier within the form. Becomes the key in submission `data`. |
| `type` | `"signature"` | Yes | Must be `signature`. |
| `label` | `string \| LocaleMap` | Yes | Label shown above the signature pad. |
| `validators` | `Validator[]` | No | Only `required` is supported. |
| `visible_when` | `string` | No | JS expression; field is shown when truthy, hidden otherwise. |

---

## Validators

### `required`

A signature must be drawn.

```yaml
validators:
  - required
```

Default error message: `This field is required.`

---

## Full example

The `signature` field from the rental application form's references section:

```yaml
version: 1
title: Rental Application
sections:
  - id: references
    title: References
    fields:
      - id: signature
        type: signature
        label: Signature
        validators:
          - required
    next: done
```
