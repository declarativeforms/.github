title: "Sections"

A section represents a single page or step within a form. Each section contains fields and defines where the user navigates after completing it.

## Properties

<ParamField path="id" type="string" required>
  Unique identifier for the section. Referenced by other sections' `next` values for navigation.
</ParamField>

<ParamField path="title" type="LocalizedText" required>
  Display title of the section. Accepts a plain string or a [locale map object](/reference/localization). Supports [Handlebars templating](/reference/templating).
</ParamField>

<ParamField path="fields" type="Field[]" required>
  Ordered array of [field objects](/reference/fields/overview) displayed in this section.
</ParamField>

<ParamField path="next" type="string | ConditionalNext[]" required>
  Defines navigation when the user completes this section. See [Navigation](#navigation) below.
</ParamField>

## Navigation

The `next` property supports four navigation modes.

### Static navigation

Navigate to a specific section by its `id`.

```yaml
next: "section_2"
```

### Done

Complete the form and show the [completion screen](/reference/completion).

```yaml
next: "done"
```

### External redirect

Redirect the user to an external URL after completing the section.

```yaml
next: "https://example.com/thank-you"
```

### Conditional navigation

An array of rules evaluated top-to-bottom. The first rule whose `when` expression evaluates to `true` determines the target. See [Conditional Logic](/reference/conditional-logic) for expression syntax.

```yaml
next:
  - when: "data.age >= 18"
    go: "adult_section"
  - else: "minor_section"
```

#### `ConditionalNext` object

<ParamField path="when" type="string">
  Expression that evaluates against form data. Required on all rules except the final `else` rule.
</ParamField>

<ParamField path="go" type="string">
  Target section `id`, `"done"`, or a URL. Used with `when`.
</ParamField>

<ParamField path="else" type="string">
  Fallback target when no preceding `when` rule matches. Only valid on the last item in the array.
</ParamField>

#### Precedence

Rules are evaluated **top-to-bottom**; the first matching `when` wins. If no rule matches and no `else` is present, navigation defaults to `"done"`.

## Example

```yaml
sections:
  - id: eligibility
    title: "Eligibility Check"
    fields:
      - id: age
        type: number
        label: "Your Age"
      - id: country
        type: dropdown
        label: "Country of Residence"
        options:
          - label: "United States"
            value: "us"
          - label: "Canada"
            value: "ca"
          - label: "Other"
            value: "other"
    next:
      - when: "data.age < 13"
        go: "ineligible"
      - when: "data.country == 'other'"
        go: "international"
      - else: "contact_info"

  - id: contact_info
    title: "Contact Information"
    fields:
      - id: email
        type: email
        label: "Email"
    next: "done"

  - id: international
    title: "International Applicants"
    fields:
      - id: visa_status
        type: short_text
        label: "Visa Status"
    next: "contact_info"

  - id: ineligible
    title: "Ineligible"
    fields:
      - id: notice
        type: hidden
        value: "ineligible"
    next: "done"
```
