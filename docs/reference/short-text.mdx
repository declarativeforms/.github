---
title: short_text
description: Single-line text input field with character count and pattern validation.
---

```yaml
- id: name
  type: short_text

  label: Full Name                     # Required. String or localized object.
  placeholder: Jane Smith              # Optional. String or localized object.

  # visible_when: data.show_name == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. Field must not be empty.

    - type: min                        # Optional. Minimum character count.
      value: 2
      # message: Must be at least 2 characters.  # Optional. String or localized.

    - type: max                        # Optional. Maximum character count.
      value: 100
      # message: Must be 100 characters or fewer.

    - type: pattern                    # Optional. Custom regex validation.
      regex: "^[A-Za-z ]+$"
      # message: Only letters and spaces allowed.
```
