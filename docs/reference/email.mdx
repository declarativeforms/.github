---
title: email
description: Email input field with optional one-time-password verification.
---

```yaml
- id: email
  type: email

  label: Email Address                 # Required. String or localized object.
  placeholder: jane@example.com        # Optional. String or localized object.

  otp: true                            # Optional. Boolean. Default: false.
                                       # Sends a 6-digit verification code to the address.
                                       # Code expires after 10 minutes.
                                       # User can resend after 30 seconds.
                                       # Maximum 5 verification attempts per code.

  # visible_when: data.notify == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. Field must not be empty.

    - type: min                        # Optional. Minimum character count.
      value: 5
      # message: Must be at least 5 characters.  # Optional. String or localized.

    - type: max                        # Optional. Maximum character count.
      value: 254
      # message: Must be 254 characters or fewer.

    - type: pattern                    # Optional. Restrict to a domain.
      regex: "^.+@company\\.com$"
      # message: Please use your company email.
```
