## Minimal example

```yaml
version: 1
title: URL Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: url
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: URL Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: url
        label: Base variant

      - id: field_2
        type: url
        label: Placeholder variant
        placeholder: https://example.com

      - id: field_3
        type: url
        label: Validator variant
        validators:
          - required
          - type: min
            value: 10
            message:
              en: Minimum 10 characters.
              es: Minimo 10 caracteres.
          - type: max
            value: 200
            message:
              en: Maximum 200 characters.
              es: Maximo 200 caracteres.
          - type: pattern
            regex: "^https?://.+$"
            message:
              en: Use a valid HTTP or HTTPS URL.
              es: Usa una URL valida HTTP o HTTPS.

      - id: field_4
        type: url
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: https://localized.example
          es: https://localizado.ejemplo

      - id: field_5
        type: url
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
