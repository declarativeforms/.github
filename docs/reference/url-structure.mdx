## Form URL pattern

```
https://app.declarativeforms.com/{owner}/{repo}/{file}
```

| Segment | Description |
|---------|-------------|
| `{owner}` | GitHub username or organization name |
| `{repo}` | GitHub repository name |
| `{file}` | YAML filename without the `.yaml` extension |

### Example

For a file at `acme/forms-repo/contact.yaml`:

```
https://app.declarativeforms.com/acme/forms-repo/contact
```

### Nested paths

Files in subdirectories are supported:

```
https://app.declarativeforms.com/acme/forms-repo/onboarding/step1
```

This fetches `https://raw.githubusercontent.com/acme/forms-repo/main/onboarding/step1.yaml`.

## Query parameters

### Prefill parameters

Any query parameter whose key matches a field ID is used to prefill that field's initial value.

```
?name=Jane&email=jane@example.com&plan=pro
```

Prefill values:
- Are case-sensitive
- Are passed as strings (no type coercion)
- Are editable by the user (except `hidden` fields)
- Apply to fields in any section

### Reserved parameters

These keys are reserved by the platform and are **never** used for field prefill:

| Parameter | Purpose |
|-----------|---------|
| `connection_id` | OAuth connection ID for private repos |
| `lang` | Force locale (`en` or `es`) |
| `submission_id` | Resume a partial submission |
| `step` | Resume at a specific section ID |

### `connection_id`

Provides an OAuth access token reference for loading forms from private GitHub repositories.

```
?connection_id=abc123
```

### `lang`

Forces the form locale. Overrides the YAML `locale` key and browser language detection.

```
?lang=es
?lang=en
```

### `submission_id` and `step`

Used for resuming a partial submission. These are set automatically by the platform after each section submission.

```
?submission_id=abc123&step=company_info
```

Both parameters must be present together. `step` must match a valid section `id` in the form.

## Thank-you page URL

After a form is completed, the browser is redirected to the thank-you page:

```
https://app.declarativeforms.com/{owner}/{repo}/{file}/thank-you?submission_id={id}
```

---

## GitHub source URL

The platform fetches the YAML from:

```
https://raw.githubusercontent.com/{owner}/{repo}/main/{file}.yaml
```

For private repos, this fetch is authenticated using the OAuth token associated with `connection_id`.

---

## URL encoding

Field prefill values with special characters must be URL-encoded:

| Character | Encoded |
|-----------|---------|
| Space | `+` or `%20` |
| `@` | `%40` |
| `&` | `%26` |
| `=` | `%3D` |
| `,` | `%2C` |

Example:

```
?name=Jane+Smith&company=Acme%2C+Inc.&email=jane%40example.com
```
