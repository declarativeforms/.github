---
title: rating
description: Star-rating field with configurable scale and optional endpoint labels.
---

```yaml
- id: satisfaction
  type: rating

  label: How satisfied are you?        # Required. String or localized object.

  min_label: Not satisfied             # Optional. String or localized. Label below minimum.
  max_label: Very satisfied            # Optional. String or localized. Label below maximum.

  # visible_when: data.used_service == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. A rating must be selected.

    - type: min                        # Optional. Minimum rating value. Default: 1.
      value: 1
      # message: Rating must be at least 1.  # Optional. String or localized.

    - type: max                        # Optional. Maximum rating value. Default: 5.
      value: 10                        # This creates a 1–10 scale.
      # message: Rating must be 10 or fewer.
```
