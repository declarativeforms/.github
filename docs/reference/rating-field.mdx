description: "YAML reference for `type: rating`."
---

## Minimal example

```yaml
version: 1
title: Rating Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: rating
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: Rating Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: rating
        label: Base variant

      - id: field_2
        type: rating
        label: Custom variant
        min_label: Low
        max_label: High

      - id: field_3
        type: rating
        label: Validator variant
        validators:
          - required
          - type: min
            value: 1
            message:
              en: Use at least 1.
              es: Usa al menos 1.
          - type: max
            value: 10
            message:
              en: Use at most 10.
              es: Usa como maximo 10.

      - id: field_4
        type: rating
        label:
          en: Localized variant
          es: Variante localizada
        min_label:
          en: Lowest
          es: Minimo
        max_label:
          en: Highest
          es: Maximo

      - id: field_5
        type: rating
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
