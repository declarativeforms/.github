---
title: File Upload
description: A field that allows users to upload one or more files.
---

## Type

```yaml
type: file_upload
```

## Properties

For shared properties (`id`, `title`, `description`, `required`, `validators`, etc.), see [Shared Properties](/reference/fields/shared-properties).

This field has no type-specific properties.

## Behavior

The field renders as a **drag-and-drop upload zone** that also supports **click-to-upload**. Uploaded files are displayed in a list showing:

- File icon
- File name
- File size
- Upload progress indicator
- Image thumbnail (for image files)

### Multiple Files

Multiple file upload is supported when the `max` validator is set to a value greater than 1.

### File Count Limits

The `min` and `max` validators control the minimum and maximum number of files.

| Validator | Helper Text Example |
|---|---|
| `min` and `max` | "2–5 files" |
| `min` only | "At least 2 file(s)" |
| `max` only | "Up to 5 files" |

When the maximum number of files is reached, the message **"Maximum number of files ({max}) reached"** is displayed and further uploads are disabled.

### Storage

Uploaded files are stored as URLs.

## Submission Format

- **Single file** (`max` is 1): `string` — URL of the uploaded file.
- **Multiple files** (`max` > 1): `string[]` — Array of URLs.

## Supported Validators

- `required`
- `min` — Minimum number of files.
- `max` — Maximum number of files.
- Expression validators

## Example

```yaml
- id: documents
  type: file_upload
  title: Upload your documents
  validators:
    - type: required
      message: Please upload at least one file.
    - type: min
      value: 2
      message: Please upload at least 2 files.
    - type: max
      value: 5
      message: You may upload up to 5 files.
```
