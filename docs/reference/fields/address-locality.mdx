## Type

```yaml
type: address_locality
```

## Description

Renders an autocomplete input powered by Google Places, restricted to locality-level suggestions (cities, towns). The user types a location name and selects from suggested results.

<Note>
  The `address_locality` field shares the same properties and behavior as [`address`](/reference/fields/address), differing only in the type of autocomplete suggestions shown. It restricts results to localities such as cities and towns.
</Note>

## Type-Specific Properties

<ParamField body="outputFormat" type="string" default="string">
  Controls the format of the submitted value.

  | Value          | Description                                              |
  | -------------- | -------------------------------------------------------- |
  | `"string"`     | Submits the formatted address as a plain string.         |
  | `"structured"` | Submits an object with individual address components.    |
</ParamField>

For shared properties available on all field types, see [Shared Properties](/reference/fields/shared-properties).

## Submission Format

When `outputFormat` is `"string"` (default), the field submits a formatted locality string:

```
"Springfield, IL, USA"
```

When `outputFormat` is `"structured"`, the field submits an object:

```json
{
  "formatted_address": "Springfield, IL, USA",
  "locality": "Springfield",
  "administrative_area_level_1": "IL",
  "country": "US",
  "postal_code": "62704",
  "place_id": "ChIJ..."
}
```

All properties except `formatted_address` are optional and depend on the selected place.

## Supported Validators

- `required`
- Expression validators

## Example

```yaml
- id: city
  type: address_locality
  label: City
  required: true
  outputFormat: string
```
