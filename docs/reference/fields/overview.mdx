# Field Types

Declarative Forms supports 21 field types. Each field is defined in YAML with a `type` property that determines its rendering and validation behavior.

<Note>
All field types share a common set of properties (`id`, `type`, `label`, `placeholder`, `validators`, `visible_when`). These are documented on the [Shared Properties](/reference/fields/shared-properties) page.
</Note>

## Text & Input

| Type | Description | Reference |
|------|-------------|-----------|
| `short_text` | Single-line text input. | [Detail](/reference/fields/short-text) |
| `long_text` | Multi-line text area. | [Detail](/reference/fields/long-text) |
| `email` | Email address input with format validation. | [Detail](/reference/fields/email) |
| `number` | Numeric input with optional min/max constraints. | [Detail](/reference/fields/number) |
| `date` | Date picker. | [Detail](/reference/fields/date) |
| `url` | URL input with format validation. | [Detail](/reference/fields/url) |
| `mobile_number` | Phone number input with country code support. | [Detail](/reference/fields/mobile-number) |

## Selection

| Type | Description | Reference |
|------|-------------|-----------|
| `dropdown` | Searchable dropdown menu with predefined options. | [Detail](/reference/fields/dropdown) |
| `single_select` | Radio-style selection of one option from a list. | [Detail](/reference/fields/single-select) |
| `multiple_select` | Checkbox-style selection of multiple options from a list. | [Detail](/reference/fields/multiple-select) |
| `rating` | Numeric rating input (e.g. star rating). | [Detail](/reference/fields/rating) |

## Location & Address

| Type | Description | Reference |
|------|-------------|-----------|

| `address_region` | State, province, or region input. | [Detail](/reference/fields/address-region) |
| `address_country` | Country selector. | [Detail](/reference/fields/address-country) |

## Media & Capture

| Type | Description | Reference |

## Utility

| Type | Description | Reference |
|------|-------------|-----------|

## Example

A form using several field types:

```yaml
fields:
  - id: full_name
    type: short_text
    label: "Full name"

  - id: bio
    type: long_text
    label: "Tell us about yourself"

  - id: country
    type: address_country
    label: "Country"

  - id: rating
    type: rating
    label: "How would you rate your experience?"

  - id: resume
    type: file_upload
    label: "Upload your resume"
```
