title: "Email"

An email address input with optional one-time password (OTP) verification and free email provider blocking.

## Type

```yaml
type: email
```

## Properties

<ParamField path="otp" type="boolean" default={false}>
  Enables email verification via one-time password. When enabled, the user must verify their email address before the form can be submitted.

  The verification flow renders as:

  1. Email input with a **Send code** button.
  2. A 6-digit verification code input with a **Verify** button.
  3. A **Resend** option becomes available after 30 seconds.
</ParamField>

<ParamField path="block_free_email" type="boolean" default={false}>
  Blocks free email providers such as `gmail.com`, `yahoo.com`, `hotmail.com`, `outlook.com`, and others. When a free email address is entered, the field displays the error: *"Please use a work email address."*
</ParamField>

Shared properties (`id`, `type`, `label`, `placeholder`, `validators`, `visible_when`) are documented on the [Shared Properties](/reference/fields/shared-properties) page.

## Validation behavior

The following validators are supported:

| Validator    | Behavior                                      |
| ------------ | --------------------------------------------- |
| `required`   | Field must not be empty.                      |
| `pattern`    | Value must match the provided regex.          |
| `min_length` | Value must meet the minimum character count.  |
| `max_length` | Value must not exceed the maximum character count. |
| `expression` | Value must satisfy the custom expression.     |

When `otp` is `true`, the email address must be verified before submission regardless of other validators.

When `block_free_email` is `true`, the free-provider check runs before any other validators.

## Submission format

```json
{
  "field_id": "string"
}
```

The submitted value is a `string` containing the email address.

## Example

```yaml
- id: work_email
  type: email
  label: Work email
  placeholder: you@company.com
  otp: true
  block_free_email: true
  validators:
    - type: required
      message: Email address is required.
```
