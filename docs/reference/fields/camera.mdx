---
title: Camera
description: A field that captures an image using the device camera.
---

## Type

```yaml
type: camera
```

## Properties

For shared properties (`id`, `title`, `description`, `required`, `validators`, etc.), see [Shared Properties](/reference/fields/shared-properties).

### Type-Specific Properties

<ParamField path="facing_mode" type="string" optional>
  Preferred camera direction. If the preferred camera is unavailable, falls back to any available camera.

  **Values:**
  - `"front"` — User-facing (selfie) camera.
  - `"rear"` — Environment-facing camera.
</ParamField>

## Behavior

The field renders the following interaction sequence:

1. An **"Open camera"** button is displayed.
2. Activating the button opens a **live camera preview**.
3. A **"Capture"** button allows the user to take a photo.
4. After capture, a **preview of the captured image** is displayed with a **"Retake"** option.

The captured image is uploaded and stored as a URL.

### Error Messages

| Condition | Message |
|---|---|
| Permission denied | Displayed when camera access is denied by the user or device. |
| Camera not found | Displayed when no camera is detected on the device. |
| Access failed | Displayed when camera access fails for any other reason. |

## Submission Format

`string` — URL of the captured image.

## Supported Validators

- `required`
- Expression validators

## Example

```yaml
- id: photo
  type: camera
  title: Take a photo
  facing_mode: rear
  validators:
    - type: required
      message: A photo is required.
```
