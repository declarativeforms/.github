## Type

```yaml
type: address_region
```

## Description

Renders an autocomplete input powered by Google Places, restricted to administrative region-level suggestions (states, provinces). The user types a region name and selects from suggested results.

<Note>
  The `address_region` field shares the same properties and behavior as [`address`](/reference/fields/address), differing only in the type of autocomplete suggestions shown. It restricts results to administrative regions such as states and provinces.
</Note>

## Type-Specific Properties

<ParamField body="outputFormat" type="string" default="string">
  Controls the format of the submitted value.

  | Value          | Description                                              |
  | -------------- | -------------------------------------------------------- |
  | `"string"`     | Submits the formatted address as a plain string.         |
  | `"structured"` | Submits an object with individual address components.    |
</ParamField>

For shared properties available on all field types, see [Shared Properties](/reference/fields/shared-properties).

## Submission Format

When `outputFormat` is `"string"` (default), the field submits a formatted region string:

```
"Illinois, USA"
```

When `outputFormat` is `"structured"`, the field submits an object:

```json
{
  "formatted_address": "Illinois, USA",
  "administrative_area_level_1": "Illinois",
  "country": "US",
  "place_id": "ChIJ..."
}
```

All properties except `formatted_address` are optional and depend on the selected place.

## Supported Validators

- `required`
- Expression validators

## Example

```yaml
- id: state
  type: address_region
  label: State / Province
  required: true
  outputFormat: structured
```
