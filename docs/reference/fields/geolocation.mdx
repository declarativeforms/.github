## Type

```yaml
type: geolocation
```

## Description

Renders a "Use my location" button. When activated, requests browser geolocation permission and captures the user's current coordinates. Displays a map preview of the captured location. The position progressively refines accuracy over approximately 3 seconds.

An accuracy indicator is shown alongside the result:

| Indicator        | Meaning                          |
| ---------------- | -------------------------------- |
| Very precise     | Highest confidence in position   |
| Precise          | High confidence in position      |
| Approximate      | Moderate confidence in position  |
| Less accurate    | Lower confidence in position     |

The user can clear the captured location to reset the field.

## Type-Specific Properties

This field has no type-specific properties.

For shared properties available on all field types, see [Shared Properties](/reference/fields/shared-properties).

## Submission Format

Submits an object with the captured coordinates and metadata:

```json
{
  "latitude": 37.7749,
  "longitude": -122.4194,
  "accuracy": 10,
  "timestamp": 1700000000000
}
```

| Property    | Type   | Description                                        |
| ----------- | ------ | -------------------------------------------------- |
| `latitude`  | number | Latitude in decimal degrees.                       |
| `longitude` | number | Longitude in decimal degrees.                      |
| `accuracy`  | number | Position accuracy in meters.                       |
| `timestamp` | number | Unix timestamp (milliseconds) of the capture time. |

## Error Messages

The following errors may be shown to the user when geolocation capture fails:

- **Permission denied** — the user declined the location permission prompt.
- **Position unavailable** — the device could not determine its position.
- **Timeout** — the location request exceeded the allowed time.
- **Not supported** — the device or browser does not support geolocation.

For the full list of error messages, see [Error Messages](/reference/error-messages).
