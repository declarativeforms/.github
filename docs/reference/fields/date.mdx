A native date picker for collecting date values.

## Type

```yaml
type: date
```

## Properties

This field type has no type-specific properties.

Shared properties (`id`, `type`, `label`, `placeholder`, `validators`, `visible_when`) are documented on the [Shared Properties](/reference/fields/shared-properties) page.

## Validation behavior

The following validators are supported:

| Validator    | Behavior                                      |
| ------------ | --------------------------------------------- |
| `required`   | Field must not be empty.                      |
| `min`        | Performs **date comparison** — the selected date must be on or after the specified date. Use ISO date strings (e.g., `"2024-01-01"`). |
| `max`        | Performs **date comparison** — the selected date must be on or before the specified date. Use ISO date strings (e.g., `"2024-12-31"`). |
| `expression` | Value must satisfy the custom expression.     |

The `min` and `max` validators compare values as dates, not as strings.

## Submission format

```json
{
  "field_id": "string"
}
```

The submitted value is a `string` containing the date value.

## Example

```yaml
- id: start_date
  type: date
  label: Start date
  validators:
    - type: required
      message: Start date is required.
    - type: min
      value: "2024-01-01"
      message: Date must be on or after January 1, 2024.
    - type: max
      value: "2025-12-31"
      message: Date must be on or before December 31, 2025.
```
