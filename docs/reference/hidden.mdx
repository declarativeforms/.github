---
title: hidden
description: Invisible field populated exclusively via URL parameters.
---

`hidden` fields are never rendered in the form. They capture values injected via URL query parameters and store them in the submission data.

**Submission value type:** `string` — the value of the matching URL parameter, or absent from submission data if the parameter was not present.

---

## Field properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier within the form. Must match the URL parameter name to capture. |
| `type` | `"hidden"` | Yes | Must be `hidden`. |

`hidden` fields do not support `label`, `placeholder`, `validators`, or `visible_when`.

---

## How it works

When the form URL includes a query parameter whose name matches the field `id`, the platform captures that value and stores it in submission data.

```
https://app.declarativeforms.com/{owner}/{repo}/rental?source=zillow
```

With a `hidden` field `id: source`, the submission will contain `"source": "zillow"` in its `data` object. The applicant never sees this field.

See [Pre-fill Fields from the URL](/guides/prefill) for how prefill works across all field types.

---

## Full example

The `source` field from the rental application form's references section:

```yaml
version: 1
title: Rental Application
sections:
  - id: references
    title: References
    fields:
      - id: source
        type: hidden
    next: done
```
