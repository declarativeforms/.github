---
title: date
description: Date picker field with optional min/max date range validation.
---

```yaml
- id: event_date
  type: date

  label: Event Date                    # Required. String or localized object.
  placeholder: Select a date           # Optional. String or localized object.

  # visible_when: data.attending == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. Field must not be empty.

    - type: min                        # Optional. Earliest allowed date. ISO date string.
      value: "2025-01-01"
      # message: Date must be in 2025 or later.  # Optional. String or localized.

    - type: max                        # Optional. Latest allowed date. ISO date string.
      value: "2025-12-31"
      # message: Date must be in 2025.

    - type: pattern                    # Optional. Custom regex validation.
      regex: "^2025-"
      # message: Only 2025 dates are accepted.
```
