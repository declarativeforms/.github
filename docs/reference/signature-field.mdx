description: "YAML reference for `type: signature`."
---

## Minimal example

```yaml
version: 1
title: Signature Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: signature
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: Signature Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: signature
        label: Base variant

      - id: field_2
        type: signature
        label: Validator variant
        validators:
          - required

      - id: field_3
        type: signature
        label:
          en: Localized variant
          es: Variante localizada

      - id: field_4
        type: signature
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
