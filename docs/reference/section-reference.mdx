---
title: Section Reference
description: "YAML reference for a form section object."
---

## Minimal example

```yaml
version: 1
title: Section Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: short_text
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: Section Full Configuration
sections:
  - id: section_1
    title: Done Variant
    fields:
      - id: field_1
        type: short_text
        label: Field 1
    next: done

  - id: section_2
    title: Section ID Variant
    fields:
      - id: field_2
        type: short_text
        label: Field 2
    next: section_3

  - id: section_3
    title: HTTPS URL Variant
    fields:
      - id: field_3
        type: short_text
        label: Field 3
    next: https://example.com/complete

  - id: section_4
    title: Rule List Variant
    fields:
      - id: field_4
        type: single_select
        label: Field 4
        options:
          - Option A
          - Option B
          - Option C
        validators:
          - required
    next:
      - when: data.field_4 == "Option A"
        go: section_5
      - when: data.field_4 == "Option B"
        go: section_6
      - else: done

  - id: section_5
    title: Rule Target A
    fields:
      - id: field_5
        type: short_text
        label: Field 5
    next: done

  - id: section_6
    title:
      en: Rule Target B
      es: Destino de regla B
    fields:
      - id: field_6
        type: short_text
        label: Field 6
    next: done
```
