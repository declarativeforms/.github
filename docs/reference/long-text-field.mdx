## Minimal example

```yaml
version: 1
title: Long Text Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: feedback
        type: long_text
        label: Feedback
    next: done
```

## Full configuration example

```yaml
version: 1
title: Long Text Full Configuration
sections:
  - id: section_1
    title: Feedback
    fields:
      - id: feedback_type
        type: single_select
        label: Feedback type
        options:
          - bug
          - feature
          - general
        validators:
          - required

      - id: feedback_details
        type: long_text
        label:
          en: Feedback details
          es: Detalles de comentarios
        placeholder:
          en: Tell us what happened
          es: Cuentanos lo que paso
        visible_when: data.feedback_type != ""
        validators:
          - required
          - type: min
            value: 20
            message:
              en: Use at least 20 characters.
              es: Usa al menos 20 caracteres.
          - type: max
            value: 1000
            message:
              en: Use 1000 characters or fewer.
              es: Usa 1000 caracteres o menos.
          - type: pattern
            regex: "^[\\s\\S]*$"
            message:
              en: Invalid content.
              es: Contenido invalido.
    next: done
```
