## Minimal example

```yaml
version: 1
title: Long Text Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: long_text
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: Long Text Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: long_text
        label: Base variant

      - id: field_2
        type: long_text
        label: Placeholder variant
        placeholder: Enter detailed text

      - id: field_3
        type: long_text
        label: Validator variant
        validators:
          - required
          - type: min
            value: 20
            message:
              en: Minimum 20 characters.
              es: Minimo 20 caracteres.
          - type: max
            value: 1000
            message:
              en: Maximum 1000 characters.
              es: Maximo 1000 caracteres.
          - type: pattern
            regex: "^[A-Za-z0-9\\s.,!?'-]+$"
            message:
              en: Use letters, numbers, spaces, and basic punctuation.
              es: Usa letras, numeros, espacios y puntuacion basica.

      - id: field_4
        type: long_text
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: Enter localized detailed text
          es: Ingresa texto detallado localizado

      - id: field_5
        type: long_text
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
