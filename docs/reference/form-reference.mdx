---
title: Form Reference
description: "YAML reference for the top-level `form` object."
---

## Minimal example

```yaml
version: 1
title: Form Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: short_text
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
id: form_1
title: Form Full Configuration
description: Form description
completion:
  title: Completion title
  message: Completion message
  button:
    label: Continue
    url: https://example.com/complete
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: short_text
        label: Field 1
        placeholder: Enter text
        validators:
          - required
    next: done
connections:
  - type: webhook
    url: https://example.com/webhook
  - type: email
    to: team@example.com
    subject: New submission
    body: Submission received
    include_responses: true
  - type: airtable
    connection_id: connection_1
    base_id: app1234567890
    table_id_or_name: Table 1
start_date: 2030-01-01T00:00:00.000Z
end_date: 2030-12-31T23:59:59.999Z
locale: en
mixpanel: project_token
```
