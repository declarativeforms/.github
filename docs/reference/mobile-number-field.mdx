## Full configuration example

```yaml
version: 1
title: Mobile Number Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: mobile_number
        label: Base variant

      - id: field_2
        type: mobile_number
        label: Placeholder variant
        placeholder: +1 555 123 4567

      - id: field_3
        type: mobile_number
        label: Validator variant
        validators:
          - required
          - type: pattern
            regex: "^[0-9+() -]{7,20}$"
            message:
              en: Enter a valid mobile number pattern.
              es: Ingresa un patron de numero movil valido.

      - id: field_4
        type: mobile_number
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: Enter localized mobile number
          es: Ingresa numero movil localizado

      - id: field_5
        type: mobile_number
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
