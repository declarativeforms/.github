---
title: "Connections"
description: "Integrations that fire when a form is submitted."
---

Connections are integrations that execute when a form is submitted. They are defined in the top-level `connections` array of your form YAML.

## Connection Types

Three connection types are available:

| Type | Fires On | Description |
| --- | --- | --- |
| [`webhook`](/reference/connections/webhook) | Every submission (including partial) | Sends submission data as JSON to a URL |
| [`airtable`](/reference/connections/airtable) | Completed submissions only | Sends submission data to an Airtable table |
| [`email`](/reference/connections/email) | Completed submissions only | Sends an email with submission data |

## Behavior

- Multiple connections can be defined in a single form. All connections are processed when their trigger condition is met.
- Webhook connections fire on **every** submission, including partial saves.
- Airtable and email connections fire **only** on completed submissions.

## Example

```yaml
connections:
  - type: webhook
    url: "https://example.com/hook"

  - type: airtable
    connection_id: "con_abc123"
    base_id: "appXYZ789"
    table_id_or_name: "Responses"

  - type: email
    to: "team@example.com"
    subject:
      en: "New submission received"
```
