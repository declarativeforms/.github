---
title: "Airtable Connection"
description: "Reference for the Airtable connection type."
---

An Airtable connection sends submission data to a specified Airtable table. Fires **only** on completed submissions. The data is sent as `{ fields: submissionData }` to the target table.

## Properties

<ParamField path="type" type="string" required>
  Must be `"airtable"`.
</ParamField>

<ParamField path="connection_id" type="string" required>
  The connection identifier obtained via the OAuth authorization flow. See [Obtaining a Connection ID](#obtaining-a-connection-id).
</ParamField>

<ParamField path="base_id" type="string" required>
  The Airtable base ID (e.g. `"appXYZ789"`).
</ParamField>

<ParamField path="table_id_or_name" type="string" required>
  The name or ID of the target table within the base.
</ParamField>

## Example

```yaml
connections:
  - type: airtable
    connection_id: "con_abc123"
    base_id: "appXYZ789"
    table_id_or_name: "Form Responses"
```

## Obtaining a Connection ID

To use an Airtable connection, you must first complete an OAuth authorization flow to connect your Airtable account:

1. Navigate to the connections page.
2. Initiate the Airtable OAuth authorization flow.
3. Authorize access to your Airtable account.
4. After successful authorization, the connection page displays the `connection_id`.
5. Copy the `connection_id` and use it in your form YAML.
