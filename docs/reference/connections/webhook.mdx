---
title: "Webhook Connection"
description: "Reference for the webhook connection type."
---

A webhook connection sends a POST request with the full submission data as JSON to a specified URL. Webhook connections fire on **every** submission, including partial saves.

## Properties

<ParamField path="type" type="string" required>
  Must be `"webhook"`.
</ParamField>

<ParamField path="url" type="string" required>
  The endpoint URL that receives a POST request with the full submission data as JSON.
</ParamField>

## Payload

The webhook payload is the complete submission object:

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Unique submission identifier |
| `form_id` | `string` | Identifier of the form |
| `data` | `object` | Field values keyed by field ID |
| `metadata` | `object` | Contains `ip_address` and `user_agent` |
| `status` | `string` | `"partial"` or `"completed"` |
| `created_at` | `string` | ISO 8601 timestamp |
| `updated_at` | `string` | ISO 8601 timestamp |

## Example

```yaml
connections:
  - type: webhook
    url: "https://example.com/submissions"
```
