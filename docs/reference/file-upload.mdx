---
title: file_upload
description: File upload field with min/max file count validation.
---

```yaml
- id: resume
  type: file_upload

  label: Upload Resume                 # Required. String or localized object.
  placeholder: PDF or Word document    # Optional. String or localized object.

  # visible_when: data.applying == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. At least one file must be uploaded.

    - type: min                        # Optional. Minimum number of files.
      value: 1
      # message: Upload at least 1 file.  # Optional. String or localized.

    - type: max                        # Optional. Maximum number of files.
      value: 3
      # message: Upload no more than 3 files.
```
