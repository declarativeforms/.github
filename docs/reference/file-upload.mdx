---
title: file_upload
description: File picker for document and image attachments.
---

`file_upload` renders a file picker. The applicant selects a file from their device; the platform uploads it and stores a reference URL in the submission data.

**Submission value type:** `string` — a URL to the uploaded file.

---

## Field properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier within the form. Becomes the key in submission `data`. |
| `type` | `"file_upload"` | Yes | Must be `file_upload`. |
| `label` | `string \| LocaleMap` | Yes | Label shown above the file picker. |
| `validators` | `Validator[]` | No | Validation rules applied before the section is submitted. |
| `visible_when` | `string` | No | JS expression; field is shown when truthy, hidden otherwise. |

---

## Validators

### `required`

A file must be uploaded.

```yaml
validators:
  - required
```

Default error message: `This field is required.`

---

### `type: min`

Minimum number of files for multi-file uploads.

```yaml
validators:
  - type: min
    value: 1
```

---

### `type: max`

Maximum number of files for multi-file uploads.

```yaml
validators:
  - type: max
    value: 3
```

---

## Full example

The `id_document` field from the rental application form's references section:

```yaml
version: 1
title: Rental Application
sections:
  - id: references
    title: References
    fields:
      - id: id_document
        type: file_upload
        label: Upload a photo ID
        validators:
          - required
    next: done
```
