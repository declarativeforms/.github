## Top-level keys

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `version` | `number` | Yes | Schema version. Must be `1`. |
| `title` | `string \| LocaleMap` | Yes | Form display title. |
| `description` | `string \| LocaleMap` | No | Subtitle below the title. |
| `sections` | `Section[]` | Yes | One or more form sections. Minimum: 1. |
| `connections` | `Connection[]` | No | Webhook, email, and/or Airtable connections. |
| `start_date` | `string` (ISO 8601) | No | Form is inaccessible before this date. |
| `end_date` | `string` (ISO 8601) | No | Form is inaccessible after this date. |
| `locale` | `string` | No | Lock form to a locale (`en` or `es`). |
| `mixpanel` | `string` | No | Mixpanel project token for analytics. |
| `completion` | `Completion` | No | Thank-you page configuration. |

---

## Section

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier. No spaces. Used in `next` references. |
| `title` | `string \| LocaleMap` | Yes | Section heading. |
| `fields` | `Field[]` | Yes | Fields in this section. Minimum: 1. |
| `next` | `string \| NavigationRule[]` | Yes | Where to go after submission. |

### `next` values

- **String**: section `id`, `"done"`, or an `https://` URL
- **Array**: `NavigationRule[]` — see [Conditional navigation](#navigationrule)

## Field

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier within the form. Used in submission data. |
| `type` | `FieldType` | Yes | The field type. See [Field types](#field-types). |
| `label` | `string \| LocaleMap` | Yes | Field label shown to the user. |
| `placeholder` | `string \| LocaleMap` | No | Input placeholder text. |
| `options` | `Option[]` | No | For selection fields. |
| `validators` | `Validator[]` | No | Validation rules. |
| `visible_when` | `string` | No | JS expression; field shown when truthy. |
| `otp` | `boolean` | No | Enable OTP verification. Only for `email` type. |
| `searchable` | `boolean` | No | Enable search. For `dropdown` and `multiple_select`. |
| `outputFormat` | `"string" \| "structured"` | No | Address output format. Only for address types. |
| `min_label` | `string \| LocaleMap` | No | Label at min end of scale. Only for `rating`. |
| `max_label` | `string \| LocaleMap` | No | Label at max end of scale. Only for `rating`. |

## Field types

| Value | Category | Description |
|-------|----------|-------------|
| `short_text` | Input | Single-line text |
| `long_text` | Input | Multi-line textarea |
| `email` | Input | Email address (optional OTP verification) |
| `number` | Input | Integer value |
| `url` | Input | URL |
| `mobile_number` | Input | Phone/mobile number |
| `date` | Input | Date picker |
| `dropdown` | Selection | Single selection from a list (supports `searchable`) |
| `single_select` | Selection | Radio-button style single selection |
| `multiple_select` | Selection | Checkbox-style multi-selection (supports `searchable`) |
| `rating` | Selection | Numeric rating scale |
| `address` | Advanced | Full address with Google Places autocomplete |
| `address_locality` | Advanced | City/locality autocomplete |
| `address_region` | Advanced | State/region autocomplete |
| `address_country` | Advanced | Country autocomplete |

| `signature` | Advanced | HTML5 canvas signature |
| `hidden` | Advanced | Not shown; populated via URL prefill |

## Option

Options can be plain strings or structured objects:

```yaml
# Simple
options:
  - Option A
  - Option B

# Structured (with translated labels)
options:
  - value: option_a
    label:
      en: Option A
      es: Opción A
```

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `value` | `string` | Yes (structured) | Value stored in submission data. |
| `label` | `string \| LocaleMap` | Yes (structured) | Displayed label. |

## Validator

```yaml
validators:
  - required
  - type: pattern
    regex: "^\\d{5}$"
    message: Please enter a 5-digit ZIP code.
  - type: min
    value: 10
  - type: max
    value: 500
    message: Must be 500 characters or fewer.
```

| Validator | Value type | Description |
|-----------|------------|-------------|
| `"required"` | — | Field must not be empty. |
| `type: pattern` | `regex: string`, `message?: string \| LocaleMap` | Input must match regex. |
| `type: min` | `value: number \| string`, `message?: string \| LocaleMap` | Min character count, numeric value, or date. |
| `type: max` | `value: number \| string`, `message?: string \| LocaleMap` | Max character count, numeric value, or date. |

<Warning>All validators are client-side only. The API does not validate submitted values server-side.</Warning>

## NavigationRule

```yaml
next:
  - when: "data.plan === 'enterprise'"
    go: enterprise_section
  - else: standard_section
```

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `when` | `string` | Yes (for conditional rules) | JS expression evaluated against `data`. |
| `go` | `string` | Yes (for conditional rules) | Section ID, `"done"`, or `https://` URL. |
| `else` | `string` | Yes (last rule) | Fallback destination. Required. |

---

## Completion

```yaml
completion:
  title: "Thanks, {{data.name}}!"
  message: We'll be in touch.
  button:
    label: Return to home
    url: https://example.com
```

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `title` | `string \| LocaleMap` | No | Thank-you page heading. Supports `{{data.fieldId}}`. |
| `message` | `string \| LocaleMap` | No | Body text. Supports `{{data.fieldId}}`. |
| `button.label` | `string \| LocaleMap` | No | CTA button label. |
| `button.url` | `string \| LocaleMap` | No | CTA button URL. Supports `{{data.fieldId}}`. |

---

## LocaleMap

A locale map is an object where keys are locale codes and values are strings:

```yaml
title:
  en: My Form
  es: Mi formulario
```

Supported locales: `en`, `es`.

Any field that accepts `string | LocaleMap` can use either format.
