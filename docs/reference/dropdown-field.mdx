title: Dropdown Field
description: "YAML reference for `type: dropdown`."
---

## Minimal example

```yaml
version: 1
title: Dropdown Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: dropdown
        label: Field 1
        options:
          - Option A
          - Option B
    next: done
```

## Full configuration example

```yaml
version: 1
title: Dropdown Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: dropdown
        label: Base variant
        options:
          - Option A
          - Option B

      - id: field_2
        type: dropdown
        label: Placeholder variant
        placeholder: Select an option
        options:
          - Option A
          - Option B

      - id: field_3
        type: dropdown
        label: Custom variant
        searchable: true
        options:
          - value: option_a
            label: Option A
          - value: option_b
            label: Option B

      - id: field_4
        type: dropdown
        label: Validator variant
        options:
          - value: value_1
            label: Value 1
          - value: value_2
            label: Value 2
        validators:
          - required
          - type: pattern
            regex: "^(value_1|value_2)$"
            message:
              en: Select one allowed value.
              es: Selecciona un valor permitido.

      - id: field_5
        type: dropdown
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: Select localized option
          es: Selecciona opcion localizada
        options:
          - value: localized_1
            label:
              en: Localized Option 1
              es: Opcion Localizada 1
          - value: localized_2
            label:
              en: Localized Option 2
              es: Opcion Localizada 2

      - id: field_6
        type: dropdown
        label: Visible when variant
        options:
          - value: yes
            label: Yes
          - value: no
            label: No
        visible_when: data.field_1 == "Option A"
    next: done
```
