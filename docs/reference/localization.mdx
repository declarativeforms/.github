# Localization

Any user-facing text in a form definition can be localized using the `LocalizedText` type.

See also: [Validation](/reference/validation) for localized error messages, [Templating](/reference/templating) for dynamic content (supports localization), [Conditional Logic](/reference/conditional-logic) for expression-driven forms.

---

## `LocalizedText` type

A `LocalizedText` value is either a plain string or a locale map.

### Plain string

Used regardless of the active locale.

```yaml
label: "Full Name"
```

### Locale map

An object with locale codes as keys and translated strings as values.

```yaml
label:
  en: "Full Name"
  es: "Nombre Completo"
```

---

## Locale resolution

The active locale is determined by the following chain, in order of precedence:

| Priority | Source | Description |
| --- | --- | --- |
| 1 | `?lang=` query parameter | URL query parameter override |
| 2 | Browser locale | Detected from the user's environment |
| 3 | Form-level `locale` field | Default locale declared in the form definition |
| 4 | `"en"` | Fallback default |

The first source that provides a valid, supported locale is used.

---

## Supported UI locales

| Code | Language |
| --- | --- |
| `en` | English |
| `es` | Spanish |

---

## Locale key normalization

Locale keys are normalized before matching:

- **Case-insensitive**: `EN`, `en`, and `En` are equivalent.
- **Underscores treated as hyphens**: `en_US` is equivalent to `en-us`.

### Base locale fallback

If a region-specific locale is not found, the base locale is used. For example, `es-MX` falls back to `es`.

---

## Where localization applies

The following properties accept `LocalizedText`:

| Location | Properties |
| --- | --- |
| Form | `title`, `description` |
| Section | `title` |
| Field | `label`, `placeholder` |
| Option | `label` |
| Validator | `message` |
| Completion | `title`, `message`, `button` |
| Rating field | `min_label`, `max_label` |
| Email connection | `subject`, `body` |

---

## Example: multi-locale form

```yaml
title:
  en: "Contact Us"
  es: "Contáctenos"
description:
  en: "We'd love to hear from you."
  es: "Nos encantaría saber de usted."
locale: "en"

sections:
  - title:
      en: "Your Details"
      es: "Sus Datos"
    fields:
      - id: "name"
        type: "short_text"
        label:
          en: "Full Name"
          es: "Nombre Completo"
        placeholder:
          en: "Enter your name"
          es: "Ingrese su nombre"
        validators:
          - "required"

      - id: "email"
        type: "email"
        label:
          en: "Email"
          es: "Correo Electrónico"
        validators:
          - "required"
          - type: "pattern"
            regex: "^[^@]+@[^@]+$"
            message:
              en: "Please enter a valid email."
              es: "Ingrese un correo válido."

      - id: "satisfaction"
        type: "rating"
        label:
          en: "How would you rate us?"
          es: "¿Cómo nos calificaría?"
        min_label:
          en: "Poor"
          es: "Malo"
        max_label:
          en: "Excellent"
          es: "Excelente"

      - id: "message"
        type: "long_text"
        label:
          en: "Message"
          es: "Mensaje"
        placeholder:
          en: "Your message here..."
          es: "Su mensaje aquí..."
        validators:
          - type: "max_length"
            value: 1000
            message:
              en: "Message must be at most 1000 characters."
              es: "El mensaje debe tener como máximo 1000 caracteres."

completion:
  title:
    en: "Thank you!"
    es: "¡Gracias!"
  message:
    en: "Your response has been recorded."
    es: "Su respuesta ha sido registrada."
  button:
    en: "Submit another"
    es: "Enviar otra"
```
