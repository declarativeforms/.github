This page documents all user-facing messages displayed by the form platform.

## Form State Messages

These messages are shown when a form cannot accept submissions.

| Condition | Title | Message |
| --- | --- | --- |
| Form does not exist | Form Not Found | The form you're looking for doesn't exist or has been removed. |
| Before `start_date` | Form Not Yet Open | This form is not yet accepting submissions. |
| After `end_date` | Form Closed | This form is no longer accepting submissions. |

See also: [Form Availability](/reference/form-availability)

## Validation Messages

Validation messages are shown when a field value does not meet its constraints. Each message has a default template that can be customized via the `message` property on the [validation rule](/reference/validation).

Placeholders in curly braces (e.g. `{label}`, `{min}`, `{max}`) are replaced with actual values at display time.

| Rule | Default Message |
| --- | --- |
| Required | `{label} is required.` |
| Invalid | `{label} is invalid.` |
| Min length | `{label} must be at least {min} characters.` |
| Max length | `{label} must be at most {max} characters.` |
| Whole number | `{label} must be a whole number.` |
| Number min | `{label} must be at least {min}.` |
| Number max | `{label} must be at most {max}.` |
| Date min | `{label} must be on or after {min}.` |
| Date max | `{label} must be on or before {max}.` |
| File min | `{label} requires at least {min} file(s).` |
| File max | `{label} allows at most {max} file(s).` |
| Selection min | `{label} requires at least {min} selection(s).` |
| Selection max | `{label} allows at most {max} selection(s).` |

## Email OTP Messages

Messages shown during email one-time password verification.

| Message |
| --- |
| Please verify your email address with OTP. |
| Please use a work email address. |

<Note>
  "Please use a work email address." is shown when `block_free_email` is enabled on the email field.
</Note>

## Geolocation Errors

Messages shown when location access fails.

| Message |
| --- |
| Location access was denied. Please enable location permissions in your browser settings. |
| Your location could not be determined. Please try again. |
| Location request timed out. Please try again. |
| Geolocation is not supported by your browser. |

## Camera Errors

Messages shown when camera access fails.

| Message |
| --- |
| Camera access was denied. Please enable camera permissions in your browser settings. |
| No camera was found on this device. |
| Could not access the camera. |
