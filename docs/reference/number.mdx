---
title: number
description: Numeric input for quantities, amounts, and counts.
---

`number` renders a numeric input. The browser restricts entry to digits and decimal points.

**Submission value type:** `number` — stored as a JavaScript number, not a string.

---

## Field properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `id` | `string` | Yes | Unique identifier within the form. Becomes the key in submission `data`. |
| `type` | `"number"` | Yes | Must be `number`. |
| `label` | `string \| LocaleMap` | Yes | Label shown above the input. |
| `placeholder` | `string \| LocaleMap` | No | Placeholder text shown inside the input when empty. |
| `validators` | `Validator[]` | No | Validation rules applied before the section is submitted. |
| `visible_when` | `string` | No | JS expression; field is shown when truthy, hidden otherwise. |

---

## Validators

### `required`

Field must not be empty.

```yaml
validators:
  - required
```

Default error message: `This field is required.`

---

### `type: min`

Minimum numeric value.

```yaml
validators:
  - type: min
    value: 0
    message: Income must be a positive number.
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `value` | `number` | Yes | Minimum allowed value. |
| `message` | `string \| LocaleMap` | No | Error shown when the value is too low. |

---

### `type: max`

Maximum numeric value.

```yaml
validators:
  - type: max
    value: 1000000
    message: Please enter a realistic income amount.
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `value` | `number` | Yes | Maximum allowed value. |
| `message` | `string \| LocaleMap` | No | Error shown when the value is too high. |

---

<Warning>
Validators run in the browser before each section is submitted. They enforce UX constraints, not security guarantees. If you need server-side validation, implement it in your webhook receiver.
</Warning>

---

## Full example

The `monthly_income` field from the rental application form's employment section:

```yaml
version: 1
title: Rental Application
sections:
  - id: employment
    title: Employment
    fields:
      - id: monthly_income
        type: number
        label: Monthly income (USD)
        validators:
          - required
          - type: min
            value: 0
    next: done
```
