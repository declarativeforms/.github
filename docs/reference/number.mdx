---
title: number
description: Numeric input field that validates whole numbers by default.
---

```yaml
- id: quantity
  type: number

  label: Quantity                      # Required. String or localized object.
  placeholder: "0"                     # Optional. String or localized object.

  # visible_when: data.wants_order == 'Yes'  # Optional. JavaScript expression.

  validators:
    - required                         # Optional. Field must not be empty.

    - type: min                        # Optional. Minimum numeric value.
      value: 1
      # message: Must be at least 1.  # Optional. String or localized.

    - type: max                        # Optional. Maximum numeric value.
      value: 100
      # message: Must be 100 or fewer.

    - type: pattern                    # Optional. Overrides default whole-number validation.
      regex: "^\\d+$"                  # Default if no pattern provided: ^\\d+$ (integers only).
      # message: Only whole numbers allowed.
```
