## Minimal example

```yaml
version: 1
title: Short Text Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: full_name
        type: short_text
        label: Full name
    next: done
```

## Full configuration example

```yaml
version: 1
title: Short Text Full Configuration
sections:
  - id: section_1
    title: Applicant
    fields:
      - id: full_name
        type: short_text
        label:
          en: Full name
          es: Nombre completo
        placeholder:
          en: Enter your legal name
          es: Ingresa tu nombre legal
        visible_when: data.application_type == "individual"
        validators:
          - required
          - type: min
            value: 2
            message:
              en: Use at least 2 characters.
              es: Usa al menos 2 caracteres.
          - type: max
            value: 80
            message:
              en: Use 80 characters or fewer.
              es: Usa 80 caracteres o menos.
          - type: pattern
            regex: "^[A-Za-z' -]+$"
            message:
              en: Use letters, spaces, apostrophes, or hyphens.
              es: Usa letras, espacios, apostrofes o guiones.

      - id: application_type
        type: single_select
        label: Application type
        options:
          - value: individual
            label: Individual
          - value: company
            label: Company
        validators:
          - required
    next: done
```
