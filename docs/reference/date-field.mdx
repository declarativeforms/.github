description: "YAML reference for `type: date`."
---

## Minimal example

```yaml
version: 1
title: Date Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: date
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: Date Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: date
        label: Base variant

      - id: field_2
        type: date
        label: Placeholder variant
        placeholder: Select a date

      - id: field_3
        type: date
        label: Validator variant
        validators:
          - required
          - type: min
            value: "2026-01-01"
            message:
              en: Use a date on or after 2026-01-01.
              es: Usa una fecha el o despues de 2026-01-01.
          - type: max
            value: "2026-12-31"
            message:
              en: Use a date on or before 2026-12-31.
              es: Usa una fecha el o antes de 2026-12-31.
          - type: pattern
            regex: "^\\d{4}-\\d{2}-\\d{2}$"
            message:
              en: Use YYYY-MM-DD format.
              es: Usa formato AAAA-MM-DD.

      - id: field_4
        type: date
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: Select localized date
          es: Selecciona fecha localizada

      - id: field_5
        type: date
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
