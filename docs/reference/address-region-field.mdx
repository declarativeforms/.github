## Full configuration example

```yaml
version: 1
title: Address Region Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: address_region
        label: Base variant

      - id: field_2
        type: address_region
        label: Placeholder variant
        placeholder: Enter region

      - id: field_3
        type: address_region
        label: Validator variant
        validators:
          - required
          - type: pattern
            regex: ".+"
            message:
              en: Enter a region value.
              es: Ingresa un valor de region.

      - id: field_4
        type: address_region
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: Enter localized region text
          es: Ingresa texto de region localizado

      - id: field_5
        type: address_region
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
