---
title: Section
description: A section groups fields into a single step with navigation control.
---

```yaml
# ── Section ───────────────────────────────────────────

- id: contact                          # Required. Unique identifier.

  title: Contact Information           # Required. String or localized object.
  # title:
  #   en: Contact Information
  #   es: Datos de contacto

  # ── Fields ──────────────────────────────────────────
  # Required. See individual field type reference pages.

  fields:
    - id: name
      type: short_text
      label: Name
      validators:
        - required

  # ── Navigation ──────────────────────────────────────
  # Required. Controls what happens after this section is submitted.

  next: done                           # End the form and submit.
  # next: details                      # Go to section with id "details".
  # next: "https://example.com"        # Redirect to an external URL.

  # Conditional routing:
  # next:
  #   - when: data.attending == 'Yes'  # JavaScript expression.
  #     go: details                    # Section id to navigate to.
  #   - else: done                     # Fallback. "done" or a section id.
```
