## Minimal example

```yaml
version: 1
title: Number Minimal
sections:
  - id: section_1
    title: Section 1
    fields:
      - id: field_1
        type: number
        label: Field 1
    next: done
```

## Full configuration example

```yaml
version: 1
title: Number Full Configuration
sections:
  - id: section_1
    title: Variant Coverage
    fields:
      - id: field_1
        type: number
        label: Base variant

      - id: field_2
        type: number
        label: Placeholder variant
        placeholder: Enter whole number

      - id: field_3
        type: number
        label: Validator variant
        validators:
          - required
          - type: min
            value: 1
            message:
              en: Use a value of at least 1.
              es: Usa un valor de al menos 1.
          - type: max
            value: 100
            message:
              en: Use a value of at most 100.
              es: Usa un valor de como maximo 100.
          - type: pattern
            regex: "^\\d+$"
            message:
              en: Use whole numbers only.
              es: Usa solo numeros enteros.

      - id: field_4
        type: number
        label:
          en: Localized variant
          es: Variante localizada
        placeholder:
          en: Enter localized number
          es: Ingresa numero localizado

      - id: field_5
        type: number
        label: Visible when variant
        visible_when: data.field_1 != ""
    next: done
```
