---
title: "Multiple select"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Example form"
description: "A comprehensive multiple_select example."

sections:
  - id: section_1
    title: "Section 1"
    fields:
      - id: question_1
        type: multiple_select
        label: "Question 1"
        options:
          - "Option 1"
          - label: "Option 2"
            value: "option_2"
          - label: "Option 3"
            value: "option_3"
        validators:
          - required
          # On multiple_select, min and max control the number of selected options.
          - type: min
            value: 1
            message: "Select at least 1 option."
          - type: max
            value: 2
            message: "Select no more than 2 options."

    next: done
```
